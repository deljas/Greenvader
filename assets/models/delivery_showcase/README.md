# 納品アセット展示用コピー

TECH-3D-13の専用展示。納品元は `C:/godot/greenvader_asset_deliveries/`。
`manifest.json` に24件のID、日本語名、元フォルダ、必要ファイルごとのSHA256を記録する。
GLB24件、metadata24件、参照PNG9件の計57件のみをコピーした。`.blend`や全候補はコピーしていない。

- BLD: 007 / 038 / 079 / 123
- VIN: 007 / 032 / 047 / 060
- MOS: 003 / 012 / 024 / 035
- TRE: 001 / 027 / 054 / 074
- GND: 009 / 036 / 059 / 077
- PRP: 001 / 041 / 075 / 121

GLBは納品どおりのY-up、m単位、scale1。横方向の中心と接地高さだけを実mesh AABBで調整し、
植物の壁/床/曲面は各metadataに従って展示する。ツタの壁、窓、ひさし、内角と根元曲面は
専用スクリプトが作る簡単な受け面であり、納品モデルには含めない。

水たまりは納品材質のまま表示する。既存小マップの反射材質への接続、成長、衝突、主人公、
本番マップへの組込み、性能負荷と最終美術評価は今回対象外。

起動は `launchers/labs/run_asset_showcase.bat`。
上部のカテゴリ/ID選択と「カテゴリ全景」、WASD/矢印で移動、Q/Eまたはホイールでズーム。
1〜6でカテゴリ移動、Tabでそのカテゴリの次のID、Rでカテゴリ全景。
太陽スライダーは方位0〜360°、仰角5〜85°。表示は640×360から整数倍nearest。

納品metadata内の過去のNOT_RUNは、元資料の記録として変更していない。
今回のGodot展示結果は `evidence/asset-showcase/self/` に別記する。
