# 街区試作用の納品コピー

TECH-3D-15。元は `C:/godot/greenvader_asset_deliveries/`、元ファイルは編集しない。
`manifest.json` に15種類、出典、GLB/metadata/必要PNG42ファイルのSHA256を記録する。

- 建物7種: BLD-007 / 019 / 038 / 046 / 079 / 091 / 123。
- 小物7種: PRP-001 / 005 / 012 / 017 / 034 / 041 / 075。
- 少数の既存樹木: TRE-001。

元scaleと材質を維持し、GLBの実AABBで中心・接地を合わせる。建物は7棟、樹木は2本、
街灯は4本など同じ資源を複数配置する。元 `.blend` と全納品候補はコピーしていない。
建物の接地高さにある垂直三角形から簡易衝突矩形を作るため、屋根を丸ごとの壁にせず、
外廊下や入口前の空間をできるだけ残す。階段・屋内探索の完成仕様ではない。

`launchers/labs/run_town_lab.bat` で専用試作を起動。WASD/矢印で歩行、Fで全景/追従、Rで開始地点。
時刻sliderと朝/昼/夕/夜、再生/停止、速度、ズームは画面上部。太陽は画面右の東から南を経て西へ。
夜の月光と、主な街灯1灯に合わせた人影は近似。既存人間fixtureを専用actorで照明し、
身長はズームと独立。通常ゲームや既存labの資源・スクリプトは変更していない。

4枚の水面は専用の不規則meshと反射viewportを使い、床・水面を反射パスから除外する。
反射像は既に照明済みなのでライト色/強度を再乗算せず、昼は太陽、夜は局所灯の減衰を
上限付きMAXで受影する。夜は近似月光が街灯の影を打ち消さない。正確な多灯PBRではない。

ゲームへの植物成長・戦闘・保存の統合、完成美術と性能保証は今回範囲外。
