## 1. 第2弾で追加する共通の約束

### 1.1 方針【ユ】

- 第1弾1.1節（敵に植物の要素を持たせない、擬態を除く）を守ります。
- **時間限定の出現はしません**。すべての敵は常に存在し、いつでも倒せます。夜は行動が活発になるだけです（コウモリ）。
- 地形（水・建物・マス属性の恒久的な値）を壊したり書き換えたりする敵は作りません。
- 味方として働く動物は作りません。中立はミツバチ（第1弾）とガラスジカだけです。

### 1.2 向きの判定【提】

スカンク、カガミトカゲ（と第1弾のシャドーブリアン）で使います。

- 敵は向き（角度）を持ち、目標へ向かって**旋回速度の上限**つきで向きを変えます。
- 弾の「正面からの命中」は、弾の飛んできた方向（敵から見た弾の発射元の方向）と敵の向きの差が60°以内（正面120°）のときです。
- 爆風（バズーカ）は爆心から見た方向で、たいあたりは主人公の位置で判定します。

### 1.3 分類タグの追加

| タグ | 第2弾の該当 | 作用 |
|---|---|---|
| 獣 | ネッコモグラ、スカンク、カバ、ハチミツグマ、ドブネズミ、コウモリ、テツヨロイサイ | 既存のラフレシア・小麦の作用を受けます。地中のネッコモグラは、地上へ出ている間だけ作用を受けます |
| 小型 | ドブネズミ | ハエトリソウが捕まえます |
| **草食（新設）** | 第1弾: シカ、ホオブクロウサギ、コケガメ、ネバナメクジ、ハキリアリ、ミミックキャベツ、既存のバッタ／第2弾: カバ、テツヨロイサイ、ハチミツグマ（雑食だが果実を好むため含める） | リンゴの落果に引き寄せられます（P35）。対象の範囲は9節で確認します |

### 1.4 濡れたマス【提】

カミナリウナギ（E29）のために、一時的な「濡れ」を加えます。

- 主人公の水やり、スプリンクラーの給水が着弾したマスは、**6秒間「濡れ」**になります。濡れは表示だけの一時状態で、成長や給水の規則には影響しません。
- 共通基盤から「水の着弾マス」を受け取る入力が必要です（統合時の接続点）。

### 1.5 動的な日陰【提】

ヒノキ（P34）が作る日陰は、第1弾1.11節の `shade` 属性に重ねる**動的な日陰**です。ヒノキが失われると消えます。ドクダミの日陰判定は、設置時だけでなく常時の判定に変えます（第1弾P25の生産倍率の計算に影響）。

### 1.6 報酬の受け取り方

企画書の方針（地面に落ちた種を拾い集めない）に合わせ、第2弾の報酬はすべて**撃破時に共通備蓄へ即時加算**します。地面の拾い物は追加しません。

## 2. 動物の詳細

### E22 ネッコモグラ `root_mole`【ユ：地中・水で飛び出す／提：詳細】

- **見た目と由来**: 太い前足とピンクの鼻先を持つ大きなモグラ。地中を掘り進み、根をかじります。水攻めで地上へ出てくる実際の習性を対処にしています。
- **きっかけ**: 縄張り（巣穴から12m）の中に成熟した栽培植物がある。
- **狙い**: 栽培植物。根の多い株を優先します（ジャガイモ、クズの株と根のマス）。主人公は攻撃しません。
- **固有行動**: 地中を1.5m/sで進み、通った跡に**盛り土の列**（0.4mごと、10秒で消える）を残します。目標の株の真下に着くと、2秒ごとに5ダメージを与えます。株を倒すと1秒だけ地上に顔を出し（当たる）、また潜って次の株へ向かいます。クズの根のマスは1マス2秒で食べて消します。
- **地中**: 射撃・バズーカ・たいあたりは当たりません。マップの検知は、盛り土の位置で行います（擬態ではありません）。
- **水で追い出す**: 現在位置から0.8m以内に水が当たると、1秒後に地上へ飛び出し、3秒間目を回します（当たる、被ダメ×1.5）。その後また潜ります。
- **対処**: 盛り土の先端へ水をかけ、飛び出したところを撃つ。かじっている株の真下にいるので、狙いを付けやすい。
- **待機**: 巣穴の中（地中）。
- **数値**: HP20、報酬6。半径0.5m、画像16×12px。
- **保存**: 状態（burrow / move / gnaw / peek / stunned）、目標の株ID・根マス、盛り土の列（位置・消える時刻）、各時刻、HP、origin、reward_paid。

### E23 スカンク `skunk`【ユ：正面から撃つと臭気／提：詳細】

- **見た目と由来**: 白黒の縞と太い尾。危険を感じると相手へ尻を向け、臭気を噴きます。正面から撃たれる＝相手と向き合っているので、**くるりと背を向けて、撃った相手の方向へ噴く**流れにします。
- **きっかけ**: 縄張り（家から12m）の中に成熟した栽培植物がある、または主人公が6m以内。
- **狙い**: 栽培植物（かじる、3ダメージ／2秒）。主人公は攻撃しません。
- **固有行動**: 正面120°から射撃・バズーカ・おたすけ植物の弾が当たると、0.6秒の予兆（尾を立てて背を向ける）の後、撃った相手の方向へ扇形（長さ5m・60°）の**臭気の雲**を出します。雲は8秒残ります。間隔は6秒です。横・後ろからの命中では噴きません。たいあたりでは噴きません。
- **臭気の雲**: 中にいる主人公は移動速度×0.6。中にいるおたすけ植物は仕事を止めて立ち止まります。敵・栽培植物・草には作用しません。
- **ニンニク**: ニンニクの範囲（第1弾P18）の中では、臭気の雲が出ません（匂いが打ち消される）。
- **対処**: 回り込んで横・後ろから撃つ。ニンニクの近くで戦う。たいあたりで仕留める。
- **待機**: 家の周りを歩く。
- **数値**: HP18、移動1.4m/s、旋回90°/秒、報酬5。半径0.5m、画像16×12px。
- **保存**: 状態（idle / approach / gnaw / windup / spray_cd）、向き、雲（位置・向き・消える時刻）、各時刻、HP、origin、reward_paid。

### E24 カバ `hippo`【ユ：修正案6′／提：数値】

- **見た目と由来**: 大きな口の巨体。昼は水に浸かり、陸へ上がって草を食べる実際の習性です。
- **生息**: 水域に住み、陸へは水際から8mまでしか上がりません。水辺のない場所には配置しません。
- **きっかけ**: 水際から8m以内に、栽培植物または成熟した草がある。
- **狙い**: 水際から8m以内の栽培植物（食べる、8ダメージ／2秒）と成熟した草（2秒で1マス、段階を1つ戻す）。主人公が4m以内に来ると、主人公を狙います。
- **水中**: 背中が水面に出ているので**当たります**が、受けるダメージは×0.5です。
- **逃げ込む**: 陸で累計15ダメージを受けると、水へ戻ります（移動1.6m/s）。水中で10秒休むと、また上陸します。
- **突進**: 陸で主人公が4m以内のとき、予兆0.8秒（口を大きく開ける）→ 7m/sで2秒直進。命中25。
- **対処**: 上陸したところを撃つ。水際から離れた場所に株を置く。正面に立たない。
- **待機**: 水中で浮かぶ。
- **数値**: HP90、陸の移動1.2m/s、報酬20。半径1.2m、画像40×24px。
- **夜**: 行動の変化なし（時間限定の要素を持たせません）。
- **保存**: 状態（float / land / eat / windup / charge / retreat / rest）、累計ダメージ、目標、各時刻、HP、origin、reward_paid。

### E25 ハチミツグマ `honey_bear`【ユ：採用・名前／提：詳細】

- **見た目と由来**: 胸に三日月模様、口元が蜜で光るクマ。蜜と果実が大好物で、食べると眠くなります。
- **きっかけ**: 縄張り（家から18m）の中に、ミツバチの巣、果実の植物（イチゴ、ブドウ、スイカ、ジャイアントスイカ、リンゴ）、またはリンゴの落果がある。
- **狙い**: リンゴの落果 → ミツバチの巣 → 果実の植物の順に優先します。主人公は、攻撃してきたときだけ狙います。
- **食べる**: 落果は3秒で1つ、巣は10ダメージ／2秒、果実の植物は6ダメージ／2秒。食べた量で満腹度が増えます（落果1つ＝1、巣を壊す＝3、株を倒す＝2）。
- **満腹で眠る**: 満腹度3で家へ帰り、**眠ります**。眠っている間は動かず、被ダメ×1.5です。攻撃されても起きませんが、HPが半分を切ると起きて怒ります。
- **ミツバチ**: 巣をかじられている間、怒ったミツバチの群れはクマを刺します（第1弾E14の怒りの相手にクマを加える）。
- **怒り**: 攻撃されると立ち上がり（予兆0.8秒）、主人公へ向かって爪で攻撃します（15ダメージ／1.2秒、移動3.2m/s）。主人公が18mより離れると落ち着きます。
- **対処**: リンゴを囮にして眠らせてから倒す。正面から戦うなら、爪の予兆を見てかわす。
- **待機**: 家の周りを歩く。
- **数値**: HP80、移動2.0m/s、報酬18。半径1.0m、画像32×28px。
- **保存**: 状態（idle / approach / eat / return / sleep / enraged）、満腹度、目標、各時刻、HP、origin、reward_paid。

### E26 ドブネズミ `sewer_rat` とマンホール `manhole`【ユ：採用／提：詳細】

- **見た目と由来**: 廃墟の下水に住むネズミの群れ。マンホールを出入り口に、下水道を通って離れた場所へ現れます。
- **マンホール網**: 同じ系統のマンホール（2〜4個）で一つの**巣**として扱います（共通基盤の固定巣）。開いているマンホールが一つでもあれば、巣は生きています。
- **生産**: 開いているマンホールから、15秒ごとにネズミを1匹出します。網全体で生存6匹まで（生産扱い、報酬0）。
- **地下の移動**: ネズミはマンホールへ入ると、3秒後に同じ網の別の開いたマンホールから出てきます。
- **狙い**: 縄張り（各マンホールから10m）の栽培植物をかじる（2ダメージ／秒）。主人公は攻撃しません。
- **塞いで制圧**: マンホールのマスには、例外として**栽培植物を植えられます**（通常の栽培条件のうち、緑化済みの条件を除く）。株が乗ったマンホールは閉じます。ネズミがそこから出ようとすると、下から株をかじります（3ダメージ／2秒）。株が倒されると、マンホールはまた開きます。網のマンホールがすべて閉じると、巣を制圧した扱いになり、巣の報酬を得ます。HPの高い株（タケ、カボチャ）が向いています。
- **対処**: 出口を順に塞ぎ、残りの出口に誘導して撃つ。ハエトリソウで捕まえる。
- **数値**: ネズミ HP6、移動3.0m/s、初期配置の報酬2、半径0.3m、画像10×8px。巣の報酬30（第1弾アリ塚と同じ）。
- **保存**: 網のID、各マンホールの位置と閉じている株ID、生産の次の時刻、ネズミ（状態、地下にいる場合の出口と時刻）、HP、origin、reward_paid。

### E27 コウモリ `bat_flock`【ユ：修正案11′・夜に活発は可／提：詳細】

- **見た目と由来**: 小さな黒いコウモリの群れ（6匹）。建物の軒下に逆さにぶら下がって眠ります。光を嫌います。
- **ねぐら**: 建物のマスに隣接する地点。
- **眠り**: ぶら下がっている間は**当たります**（1発で1匹、爆風なら範囲内のすべて）。
- **起きる**: 1匹でも攻撃が当たる、または主人公が3m以内に来ると、群れ全体が飛び立ちます（飛行中は当たりません）。
- **乱れ飛び**: 主人公の周りを飛び回り、2秒ごとに1匹が急降下して噛みます（3ダメージ）。急降下と噛んだ後0.5秒は低空にいて当たります。飛ぶ時間は昼12秒、**夜24秒**（夜に活発）。その後ねぐらへ戻り、またぶら下がります。
- **光**: ヒカリゴケ（第1弾P28）の範囲では急降下しません。
- **最後の群れ**: 2匹以下になると乱れ飛ばず、すぐねぐらへ戻ります。
- **対処**: 最初の一撃をバズーカにして、まとめて落とす。急降下を引き付けて撃つ。ヒカリゴケの近くで戦う。
- **数値**: 1匹 HP4、報酬2（初期配置）。移動4.0m/s。画像8×6px。
- **保存**: ねぐらの位置、群れの状態（roost / swarm / return）、各個体（位置、急降下の状態、HP、reward_paid）、各時刻、origin。

### E28 テツヨロイサイ `iron_rhino`【ユ：水で錆びて鈍る／提：詳細】

- **見た目と由来**: 鉄板のような皮膚のサイ。関節に継ぎ目があり、水がかかると錆びて動きが鈍ります。
- **きっかけ**: 主人公が10m以内で、建物に遮られず見える。
- **狙い**: 主人公。主人公が遠いときは、進路上の栽培植物を踏み荒らします。
- **突進**: 予兆1.2秒（前脚で地面をかく）→ 9m/sで2.5秒直進。命中30、進路上の栽培植物には1株につき15ダメージ。突進の後2秒硬直します。
- **鎧**: 射撃のダメージは×0.5。バズーカ・たいあたりは減りません。
- **錆**: 水が当たるたびに錆が1つ増えます（最大5）。錆1つにつき、移動・突進の速さ−12%、予兆+0.2秒、突進の間隔+1秒。**錆は減りません**。
- **対処**: まず水をかけて錆びさせ、鈍ったところをバズーカやたいあたりで攻める。
- **待機**: 家の周り6mを歩く。
- **数値**: HP100、移動1.6m/s、報酬22。半径1.2m、画像40×28px。
- **保存**: 状態（idle / windup / charge / recover）、錆の数、突進方向、命中済みの対象、各時刻、HP、origin、reward_paid。

### E29 カミナリウナギ `thunder_eel`【ユ：採用／提：詳細】

- **見た目と由来**: 青白く光る筋を持つ大きなウナギ。放電は水を伝う、という性質の誇張です。
- **生息**: 水面のマスの中だけを泳ぎます。水面近くを泳ぐので常に当たりますが、受けるダメージは×0.75です。
- **きっかけ**: 主人公またはおたすけ植物が、水際から6m以内にいる。
- **放電**: 6秒ごとに予兆1.0秒（体が強く光る）→ 自分から半径3mに10ダメージ（主人公・おたすけ植物）。さらに、放電の範囲に**濡れたマス**（1.4節）があると、つながった濡れたマスを伝って最大10mまで届きます。その上や隣にいる主人公・おたすけ植物も10ダメージを受けます。
- **疲れ**: 放電の後2秒間は疲れて、被ダメ×1.5です。
- **対処**: ウナギの近くでは水やりを控える。放電の直後を撃つ。
- **数値**: HP35、報酬10。半径0.5m、画像22×8px。

### P29 ツキミソウ【ユ】

- **見た目**: 細い茎に淡い黄色の花。夜に開き、昼はしぼみます。
- **能力**: 夜は基準×1.5、昼は×0.3。ヒマワリ（P08）と逆の性質です。昼夜は共通基盤から受け取ります。

### P30 タンポポ【ユ：通常の種を飛ばす・自身は増えない】

- **見た目**: ギザギザの葉と黄色い花。成熟すると白い綿毛の球になります。
- **綿毛**: 成熟後、40秒ごとに綿毛を1つ飛ばします。株から3〜6マス先の、**新たに播種できる有効マス**（PoC3の範囲播種と同じ条件）を専用の乱数で1つ選び、そこに**通常の種**を1つまいた扱いにします。種は共通備蓄から消費しません。
- **増えない【ユ】**: 綿毛から生えるのは草です。タンポポの株は増えません。
- **候補がない場合**: 有効マスがなければ、その回は飛ばしません。
- **追加の保存**: 次の綿毛の時刻。

### P31 オジギソウ【ユ】

- **見た目**: 細かい羽状の葉。閉じると細い棒のようになります。
- **閉じる**: 敵（中立は除く）が2m以内に入るか、攻撃を受けると、葉を閉じます。閉じている間は被ダメ×0.2、生産0です。
- **開く**: 2m以内に敵がいなくなってから4秒で開きます。
- **相互作用**: カボチャの被ダメ軽減（×0.7）と掛け合わせます。
- **追加の保存**: 閉じているか、開く時刻。

### P32 クズ【ユ：株と根を区別、株からの距離で制限】

- **見た目**: 株は大きな三つ葉の茂み。根のマスは、地面を這うつるです。
- **根の広がり**: 成熟後、15秒ごとに、株または既存の根に隣接するマスへ根を1マス伸ばします（専用の乱数で選ぶ）。伸ばせるのは、**株の占有範囲からチェビシェフ距離4以内**で、通常の栽培条件を満たすマスだけです。根は最大24マスまでです。
- **根のマス**: 主人公とおたすけ植物は普通に歩けます。敵が通ると移動速度×0.6です。根のマスには、ほかの植物を植えられません（占有扱い）。草の成長には影響しません。
- **覆って弱らせる**: 根のマスに隣接する**ほかの種類の栽培植物**は、基礎生産量×0.8です（自分の条件による倍率として扱う、重複しない）。
- **生産**: 株の生産量は、1＋根のマス数×0.15種/分です。根は生産しません。
- **失われる**: 株を撤去するか、株が倒されると、根はすべて消えます。根のマスを1マスずつ撤去することもできます（返還0）。ネッコモグラは根のマスを食べます。
- **価格**: 根は同種の現存数に数えません。
- **追加の保存**: 根のマス一覧、次の伸長時刻。

### P33 ヘチマ【ユ】

- **見た目**: 支柱に絡むつると、細長い実。
- **貯水**: 給水されると、貯水10を得ます。貯水があれば、10秒ごとに周辺3タイルの**未給水の栽培植物**を1株給水します（貯水1を消費）。栽培植物がなければ、未給水で成長中の草を1マス給水します。給水は、共通基盤の給水イベントとして返します。
- **補充**: 貯水が10未満のとき、主人公またはスプリンクラーの水が当たると、貯水が10に戻ります。これはヘチマ自身の永続給水とは別の、ヘチマだけの例外です。スプリンクラーは、貯水が空のヘチマを「未給水の栽培植物」と同じ優先度で扱います。
- **追加の保存**: 貯水量、次の給水時刻。

### P34 ヒノキ【ユ】

- **見た目**: まっすぐ高い針葉の大木（3×3）。
- **日陰**: 成熟後、占有範囲の北側（地図の上側）2マス×幅3マスを、動的な日陰（1.5節）にします。成熟前は日陰を作りません。
- **相互作用**: ドクダミ（第1弾P25）を、ヒノキの日陰に植えれば日陰の倍率を得ます。ヒノキが失われると日陰も消え、ドクダミの倍率も消えます。
- **追加の保存**: なし（日陰は占有と成熟から計算）。

### P35 リンゴ【ユ：草食すべてを引き寄せる】

- **見た目**: 赤い実の付いた低い果樹（2×2）。
- **落果**: 成熟後、30秒ごとに、隣接する歩行可能なマスへ実を1つ落とします。1株あたり同時に3つまでです。落果は主人公が拾うものではなく、**囮**です。
- **引き寄せ**: 草食タグ（1.3節）の敵は、自分のきっかけの範囲または縄張りから10m以内に落果があれば、それを最優先の狙いにします。食べるのに3秒かかり、食べると落果は消えます。安定した地域の中の落果には引き寄せられません（再侵攻禁止）。
- **相互作用**: ハチミツグマの満腹度を増やします（E25）。
- **追加の保存**: 落果（位置）、次の落果の時刻。

### P36 ホウセンカ【ユ】

- **見た目**: 赤やピンクの小さな花と、ふくらんだ実。
- **はじける**: 成熟後、20秒ごと、または敵が1.5m以内に来たとき（間隔8秒）に実がはじけます。半径2mの敵（中立を除く）に4ダメージを与え、周り2マス以内の**新たに播種できる有効マス**から最大3マスに通常の種をまいた扱いにします（共通備蓄は消費しません）。
- **追加の保存**: 次にはじける時刻。
