## 1. 共通の約束

### 1.1 敵のデザイン方針【ユ】

- このゲームは「植物 vs 動物」です。**敵に植物の要素を持たせません**。例外は、植物に化ける・紛れる**擬態**として機能する場合だけです（コケガメ、ミミックキャベツ、クサヘビ）。キノコ（マッシュリング）は菌類のため、この除外の対象外とします。
- 名前・見た目・行動を、動物の実際の特徴（またはその誇張・変異）から論理的につなげます。由来の分からない能力は付けません。

### 1.2 単位・距離

- **1タイル = 1マス = 0.4m**（PoC2のセル）。座標は既存と同じ論理pxです（1マス=4px、1px=0.1m）。速度はm/sで記載します。主人公の歩行は4.8m/sです。
- **「周辺Nタイル」**: 効果元の占有矩形と対象の占有矩形の間の**チェビシェフ距離**（縦横斜めとも1マス=1）で測ります。最も近いマスどうしの距離が `N` 以下なら範囲内です（境界を含む）。効果元の矩形を四方へNマス広げた矩形と、対象の矩形が1マスでも重なるか、という判定と同じです。大きな植物も占有範囲全体を起点にするため、判定が一貫します。自身は常に対象外です。
- **「隣接」**: 上下左右に辺を接すること（斜めは含みません）。
- 敵の範囲（索敵・爆発など）は、中心点からのユークリッド距離（m）で測ります。

### 1.3 生産量と補正の順序

- 単位は**種/秒**です（本書では読みやすさのため種/分も併記します）。未成熟株の生産量は0です。
- 次の順で計算します。各段は、前段の結果や他株の生産量を参照しないため、循環による増幅は起こりません。
  1. **定義値**: 種類ごとの生産量。
  2. **基礎生産量** = 定義値 × 変種倍率（四葉×7、黄金の四葉×777）× **自分の条件による倍率**（ヒマワリの昼夜、トマトの壁際、ブドウの直線、イネの面積、トウモロコシの三姉妹、チャノキの熟成、サクラの開花、ドクダミの日陰、ハエトリソウの消化中）。自分の条件は、配置・時刻・自分の経過時間だけで決まります。
  3. **補正後生産量** = 基礎生産量 × (1 + 黄金系の補正 + ミツバチの補正)。外部からの補正は加算でまとめます。
  4. **横取り**: ホオブクロウサギにかじられている間、その株の補正後生産量はプレイヤーではなくウサギのほお袋へ入ります。
- ジャガイモは補正後生産量を、継続生産ではなく自分の貯蔵へ加えます（3節P21）。
- 補正は栽培植物だけに作用します。おたすけ植物、緑地の土地収入、草には作用しません。

### 1.4 範囲補正の重複

| 補正 | 1つあたり | 重複 | 上限 | 自分への作用 |
|---|---|---|---|---|
| 黄金系（生産量） | +7%（周辺7タイル） | 効果元の数 `k` だけ加算 | k=7（+49%） | なし。黄金系どうしは互いに作用 |
| ミツバチ（生産量） | +10%（巣から周辺8タイル）。花の植物は+20% | 重複しない（最大の1つ） | +20% | — |
| エダマメ（成長速度） | +5%（周辺1タイル） | 効果元の数だけ加算【ユ】 | 5株（+25%） | なし（エダマメどうしにも作用しない） |
| カボチャ（被ダメ） | ×0.7（周辺1タイル） | 重複しない | ×0.7 | なし |

「花の植物」タグ: ヒマワリ、ラベンダー、イチゴ、サクラ（開花中のみ）、キョウチクトウ。

### 1.5 成長・給水・時間

- 成長は共通基盤の規則（PoC3: 未給水は設定速度の半分、給水後は設定速度）に従います。追加コンテンツは、共通基盤の成長倍率に自分の倍率（エダマメ、ドクダミの日陰）を掛けるだけで、独自の給水規則を本番用に増設しません。確認画面ではPoC3の規則を写した**仮アダプター**を明示して使います。
- 時間はホストが `advance(dt)` を呼んだ分だけ進みます。ポーズ中・マップ表示中・一覧表示中・アプリ終了中は呼ばれないため、時間は進みません。周期（サクラの開花、ミントの増殖など）も、株自身の経過時間から計算します。

### 1.6 希少変化（四葉・黄金の四葉）

- 親種が**未成熟から成熟へ変わる瞬間に一度だけ**抽選します。株に `variant_rolled=true` と結果を保存し、再読込や成熟後の更新で再抽選しません。
- 抽選には追加コンテンツ専用の乱数を使い、その状態（seed・state）を保存します。保存→復元を挟んでも、同じ順の抽選結果になります。
- 変種化しても、**株ID・実支払額・占有範囲・給水状態・成長の経過**は保持し、種類だけを変種へ切り替えます。
- 同種価格の計算では、四葉は「クローバー」系統、黄金の四葉は「黄金のクローバー」系統に数えます（`price_family`）。価格式そのものはPoC3共通基盤の責任です。
- 確認画面の「強制抽選」は**デバッグ専用**の操作として、通常の抽選とは別の関数・表示で扱います。

### 1.7 株が失われる理由と返還

| 理由 | 返還 | 現存数 |
|---|---|---|
| 手動撤去 | 実支払額の20%（切捨て）。ジャガイモは貯蔵分を加算 | 減る |
| 敵の攻撃（突進・爆発・切り取り・食害・粘液を含む） | 0 | 減る |
| キョウチクトウの毒で枯死 | 0 | 減る |

ミントが自然に増えた株は実支払額0のため、撤去しても返還は0です。通常の植物の枯死条件（水不足では枯れない等）は変更しません。

### 1.8 敵の共通規則

- **出自と報酬**: 各個体に `origin`（`initial` 初期配置 / `produced` 生産）を持たせます。報酬は**最終撃破（HPが0）時に1回だけ**支払い、`reward_paid` を保存します。`produced` の報酬は0です。階級（近・中・遠）の倍率は共通基盤が掛けます。追加コンテンツは基礎値と `tier` を受け取ります。
- **出現**: 特に記載がなければ初期配置のみです。巣から生産されるのは、ハキリアリ（アリ塚）とミツバチの働き蜂だけです。
- **地域安定**: 生存中の敵（黒焦げ・裸・擬態中・水中・飛行中を含む）は、地域安定の判定に数えます。中立のミツバチ（巣・働き蜂）は数えません。`is_alive()` と `counts_for_stability()` を公開します。
- **安定地域**: 移動先はホストの経路判定に従い、安定した地域へ入りません。飛ぶ敵も、安定地域の上空には入りません。
- **残存効果**: 毒ガス、粘液、泥は数秒〜20秒で消えます。粘液だけは草の段階を戻すことがありますが、敵を排除した後は再緑化できるため、100%緑化の保証に影響しません。
- **擬態【ユ承認】**: 擬態中の敵は、主人公の画面とマップの両方で検知の対象外です。**見破られた時点**（動いた・攻撃が当たった・種や水が当たった・自分から攻撃した等、種類ごとに定義）から、通常の敵として表示・検知します。PoC3の「マップ上の敵・巣の表示と記憶」に対する、追加コンテンツ側の例外です。
- **飛ぶ敵【ユ承認】**: 飛行中は建物を越え、射撃は当たりません。着地中・離陸中・上昇中だけ当たります。
- **逃げる敵【ユ承認】**: 縄張り（家から一定半径）の外へは逃げません。逃げる速度は主人公より遅く（3.5m/s以下）、一定時間で疲れて止まります。追い詰めれば倒せます。
- **水中の敵【ユ承認】**: 一定の周期で必ず浮上し、岸から撃てる場所に現れます。
- **記入の約束**: 各敵について、攻撃を始めるきっかけ、狙う相手、狙う相手がいないときの行動、最後の1匹（群れ・親子の片割れ）の扱いを書きます。

- **入力**: ホスト状態の参照（主人公の位置・向き・HP、地形とマスの属性、緑化段階、植物・おたすけ植物の位置と占有、経路の可否、昼夜）と、受けた攻撃（量、種類 `shot / bazooka / tackle / water / helper / spine`、方向）。

## 2. 敵の詳細

共通の書式: **きっかけ**＝攻撃を始める条件、**狙い**＝攻撃・行動の対象、**待機**＝狙う相手がいないときの行動。PoC2の比較値は、イノシシ HP20（強敵40）・突進の予兆0.7秒、主人公の通常弾5・種バズーカ25・たいあたり8です。

### E01 シャドーブリアン `shadow_brian`【ユ：名前・黒い雄ウシ風／提：詳細】

- **見た目と由来**: 黒い剛毛の、雄ウシとイノシシの中間の大型獣。前へ突き出た太い角と分厚い額。正面が硬いのは額と角、壁に刺さるのは角、と行動につなげます。
- **既存の突進型との関係**: イノシシの「予兆→突進→硬直」の型を引き継ぎます。正面の防御と、壁に刺さる性質が固有です。
- **きっかけ**: 主人公が8m以内で、建物に遮られず見える。
- **狙い**: 主人公。主人公が8mより遠いときは、5m以内のおたすけ植物。
- **固有行動**: 予兆1.1秒（前脚で地面をかく、「！」）の後、障害物に当たるか2.5秒経つまで8m/sで直進します。建物・壁・水際・タケに衝突すると**角が刺さり3秒動けず**、その間は全方向から×1.5のダメージを受けます。外れた場合は1.5秒の硬直です。進路上の栽培植物には1株につき1回10ダメージを与えます。
- **防御**: 正面120°からの射撃は×0.25に減ります。たいあたりとバズーカの爆風は減りません。

### P01 ワサビ【ユ】

- **見た目**: 細い茎とハート形の葉、太い根茎。
- **設置条件**: 通常の栽培条件に加え、占有範囲から**チェビシェフ距離2以内に「清水」マス**があること。「清水」は水面・浅瀬マスに付ける明示的な属性で、水質のシミュレーションは行いません（1.11節）。判定は設置時だけです（水面は変化しないため）。
- **面積効率**: 7種/分/マス（クローバーの3.5倍）。
- **相互作用**: 清水の近くは植えられる場所が限られるため、ワサビ同士・他の植物と場所を取り合います。

### P02 ジャイアントスイカ【ユ】

- **見た目**: 地面にめり込むほど巨大な縞のスイカ。
- **占有と画像**: 占有6×6=36マス、画像56×40px。画像の大きさと占有範囲は独立しており、足元基準は占有範囲の中央下です。
- **設置条件**: 36マスすべてが通常の栽培条件を満たすこと。
- **面積効率**: 4.4種/分/マス（スイカ2.5より高いが、広い緑地・高い費用・長い成熟が必要）。
- **相互作用**: 大きいため、黄金系やミツバチの範囲に入りやすい反面、キョウチクトウの毒も受けやすくなります。

### P03 キョウチクトウ【ユ：能力／提：判定の詳細】

- **見た目**: 細長い葉とピンクの花の低木。根元に紫のにじみ。
- **成長**: 成熟15秒と早く、生産量も多い（4種/分/マス）。
- **毒**: 成熟後、**5秒ごと**（ゲーム内時間）に判定します。周辺3タイルにある**キョウチクトウ以外の栽培植物**の「毒の蓄積」を1増やします。複数のキョウチクトウから受けても、1回の判定で+1までです。蓄積が**3になると枯れます**（範囲内に約15秒）。範囲外へ出た株（キョウチクトウが撤去された等）は、次の判定で蓄積が0に戻ります。
- **枯死**: 株を除去して占有を解除し、現存数を減らします。返還は0です（1.7節）。
- **対象外**: 草・種・芽（地面の緑化段階）、おたすけ植物、ほかのキョウチクトウ。未成熟のキョウチクトウは毒を出しません。ニンニクの範囲内にある株は毒を受けません（P18）。
- **例外の範囲**: この能力だけの例外で、通常の植物全般の枯死条件は変更しません。
- **追加の保存**: 株ごとの毒の蓄積、次の判定時刻。

- **追加の保存**: `variant_rolled`、変種の結果（クローバー側に保存）。

### P05 黄金のクローバー【ユ】

### P10 ハス【提→ユ】

### P15 ブドウ【提→ユ】

- **イネとの違い**: ブドウは直線の長さ、イネは矩形の面積でボーナスが決まります【ユ】。

### P16 イチゴ【提→ユ】

- **ラフレシアとの違い**: 敵を遠ざけるのではなく、株への狙いだけを外します。範囲に入った敵が、通りがかりに巻き込みダメージ（突進・爆発・粘液など）を与えることはあります。

### P19 タケ【提→ユ】

- **見た目**: 細く高い竹（画像は縦長）。
- **能力**: 成長が非常に速く（8秒）、成熟したタケのマスは、**敵の移動を遮ります**（生け垣）。射撃は遮りません。敵はタケを攻撃して壊すことができます（HP80）。ブリアンやアルマジロにとっては壁と同じで、突進が刺さり、転がりが跳ね返ります。

### P20 ハエトリソウ【提→ユ】

- **能力**: 成熟後、小型タグの敵（1.9節）が占有マスかその隣接マスに入ると、捕まえて30ダメージを与えます。その後20秒は消化中で捕まえられず、その間は生産量が×3になります（「捕まえるたびに種を少し生む」を、時間で上限のある形にしたもの）。
- **報酬の扱い**: 捕まえて倒した敵の報酬は、通常の撃破と同じ規則です（初期配置のみ、1回）。生産された敵を捕まえても、消化中の生産増は20秒に1回までのため、無限に稼ぐことはできません。

### P21 ジャガイモ【提→ユ】
