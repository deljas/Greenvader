## 世界観と体験

タイトルはグリーンベーダー（green + invader）。ほとんどの生物が滅びた荒廃した地球で、植物と敵対生物が陣取り合戦を行います。主人公は足の生えた小さな花。目標は世界を緑で覆うことです。

緑化を無条件の善行とは描かず、かわいさ、美しさ、不気味さを同居させます。荒廃した世界を色とりどりの植物で支配していく景色が主な報酬です。廃ビルや看板などは完全に覆い隠さず、元の姿の面影を残しながら植物に侵略された様子を見せます。動物の死骸に植物が育つ景色も含めます。敵にはイノシシ、陸生巨大イカ、昆虫、菌類を含みます。菌類は動物ではないため、システム上は全体を「敵対生物」と呼び、独立した第三勢力の実装は初期版に要求しません。

## 基本循環

1. 安全な小さな緑の領域から出発する。
2. 種を飛ばして緑化の起点を作り、水で成長を促す。
3. 育った植物から種や支援を得る。
4. おたすけ植物を配置し、後方の種まき・給水・防衛を任せる。
5. 敵を排除し、巣を破壊して地域を安定させる。
6. 多地域化後は、敵をすべて排除して地域を安定させ、自然拡張を眺めながら次の地域の前線へ向かう。
7. 展望地点から、自分が変えた世界を確認する。

拡大するほど補給巡回が増える設計は避けます。手動補給は開拓直後や加速に使い、成熟した後方は自立します。

## プレイヤーの行動

| 行動 | 基本ルール |
|---|---|
| 移動 | WASD、マウスで照準。斜め移動だけ速くならない |
| 種まき | ふつうのたねを有限に発射。地面に着弾すると種、芽、成熟の順に育つ。敵への直撃は通常種攻撃になる |
| 水やり | 前方へ水を飛ばして成長を促す。水分ゲージを消費し、水辺で自動給水 |
| 栽培 | 植物の種類を選び、土地や前線に合わせて植える |
| スキル | スキルシードから得たポイントを配分して強化・習得。アクティブは同時に2つまで装備。後期実装 |
| 移動補助 | ゲートルート間を移動。多地域化に合わせて実装 |

実装初期値として、左クリックを種まき、右クリックを水やり、Eを調べる／回収／展望、Escをポーズとします。スキル実装時はQとRを候補にし、操作はInputMapに集約します。

種切れで詰まないよう、現行初期版では安全地帯に破壊されず最低限の通常種資源を生産する供給源を用意します。他の種資源の供給方法は未確定です。水がなくても通常の植物はゆっくり育ちます。戦闘不能時は安全地帯へ戻り、制圧済み地域と育成成果を失いません。おたすけ植物はマップから移動を指示できます。資源の重複獲得が起きないよう移動状態を保存します。

今後の種資源はジャンル別に共通の3種類とします。ふつうのたねは陣地拡大と通常種攻撃、カラフルたねは栽培植物、おたすけたねはおたすけ植物に使います。おたすけたねは他の2種類よりやや得にくくします。スキルシードはこれらの種資源とは別で、永久に保持するスキルポイントとして扱います。現行の初期版作業範囲は通常種資源と少数の植物選択のままとし、3種類への移行や回収役の導入時期は別途決めます。植物ごとの大量の加工素材は導入しません。希少な植物の種による種類解放は後期版の別要素として残します。

### 種の生産と運搬

成熟した栽培植物は定期的に種を生産し、所持数へ直接加算せず地面に落とします。主人公は近づいて回収します。種を拾って運ぶおたすけ植物（仮称「ハコビー」、名称と姿は案）も追加する方針です。これは指定地点の周囲で種を回収し、遠くの種を追いかけず、主人公を追って戦場へ運びません。回収した種は安全地帯の共通種倉庫へ運び、到着時に共通所持数へ加算して短く獲得を表示します。遠い畑の近くに別の受け渡し場所を置ける方向も採用しますが、倉庫までの具体的な転送方法は未確定です。回収役は最初の手動収穫から無理なく作れるペースを目指します。

地面の種は束にまとまります。束の上限、倉庫や所持枠が満杯のときの処理、地面に残った種の消滅期限は未確定で、無限の蓄積を保証しません。運搬中に回収役が倒された場合、運んでいた種をその場に落として回収可能にし、回収役自体は消滅します。自然拡張による緑化100％の保証は、この運搬に依存させません。ガトリンガーの成熟植物からの近距離の種受け渡しは維持し、回収役との詳しい連携は未確定です。

## マップ

画面左上に常時円形のミニマップを表示し、Mキーで全画面のオーバーレイマップを開きます。両マップ共通で、主人公やおたすけ植物の周囲一定範囲、主人公が通った場所、緑化した場所を公開し、それ以外は伏せます。一度公開された地形は陣地を失っても公開状態を保ち、緑化の現在状態は更新します。視認範囲や探索範囲の数値は未確定です。

マップにはおたすけ植物の位置を表示し、敵対生物に攻撃されている緑化タイルを強調します。マップの表示範囲に収まらない対象は輪郭に方向アイコンを表示し、おたすけ植物、攻撃を受けている場所、指定目的地を示します。近接する被攻撃箇所はまとめ、被攻撃状態は色や形でも見分けられるようにします。未発見の敵やスキルシードはマップ上にアイコン表示しません。植物の消滅など大きな変化だけを短く通知します。視認範囲とマップ表示範囲は別に扱い、アイコンの集約や表示の数値方式は未確定です。

全画面マップを開いている間は世界時間を止めます。おたすけ植物を左クリックして選ぶと、カーソルがその植物のプレビューになり、別の地点を左クリックすると移動を指示できます。既知の水面や建物など通行できない地点は、その理由を示して指示を拒否します。未探索地点への指示は仮に受け付けますが、移動後に未知の障害物が判明したり到達不能と分かったりした場合は手前で停止して知らせます。未知の地形情報を先に明かす拒否表示はしません。右クリックまたはEscで選択を解除します。モードの切替も全画面マップ上で行います。移動先やモードの予定は指示時点でマップに表示し、マップを閉じて世界が再開してから実行します。

ガトリンガー、スプリンクラー、アーミーは自力で移動できます。移動指示で目的地へ向かっている間は通常の仕事を止めます。到着後、ガトリンガーとスプリンクラーは通常の仕事を再開し、アーミーは選択中のモードを続けます。アーミーの自律行動モードは次の通りです。

| モード | 行動 |
|---|---|
| 防衛 | 指定位置の近くにいる敵を迎撃し、追い過ぎず指定位置へ戻る |
| 探索 | 未探索の場所を調べ、戦闘では自衛を優先する |
| 攻撃 | 発見済みの敵へ積極的に接近し、巣も破壊する |

移動指示と自律行動モードは別の命令です。任務が終わったアーミーは元の拠点へ戻らず、同じ地域内で最も近い緑化タイルへ移動してそこを守ります。防衛モードで敵を迎撃した際は、指定位置へ戻る動作を維持します。アーミーがモードに従って自律歩行している間の交戦の詳細は未確定です。ゲートルートにはこの移動命令を適用しません。P3作業票の遠方追跡制限などは現在の作業範囲として維持し、この企画を導入する段階で防衛モードの条件へ整合させます。

## 陣地と自然拡張

地形、陣営、成長段階を分けます。植えられない水面や建物の有無と、緑化可能な土地の範囲を明示します。種を置いただけでは緑化率に数えず、初期値では発芽済みから数えます。成熟すると自然拡張と種生産の起点になります。

自然拡張は成熟した領域から隣接する緑化可能地へかなりゆっくり進みます。手動の種まきは、これより速く前線を作ったり、離れた場所に起点を作ったりする手段です。ガトリンガーは自然拡張よりそれなりに速いペースで緑化を進め、射程内の離れた場所にも起点を作れます。敵をすべて排除して地域が安定した後は、拡散速度が少し上がります。具体的な速度や倍率は未確定です。敵の領域には、敵を排除しながら植物を定着させます。巣の占有マスには、巣を破壊するまで植物を定着させません。

陣地を広げると、固定地点に多数あるスキルシードを獲得でき、その累計獲得数が総スキルポイントになります。ポイント配分を通じて主人公を強化できます。シードは未獲得の間キラキラ輝き、シードが置かれたタイルが発芽して緑化された時点で、距離や手動回収を問わず自動獲得します。手まき、ガトリンガー、自然拡張のどの方法で緑化しても獲得でき、地域の安定を待つ必要はありません。同じシードは一度だけ獲得できます。

獲得ポイントは累計で保持し、陣地を失っても減りません。ポイントの消費ではなく配分として扱い、「配分済みポイント＋未配分ポイント＝総獲得ポイント」を保ちます。安全地帯では無料で配分を振り直せます。多地域化後もポイントを引き継ぎます。攻撃力や移動速度などのパッシブ強化と、毒ガス噴射などのアクティブスキルに配分できます。陣地の面積に応じて能力値が直接自動上昇する方式は採用せず、スキルシードを通じた成長とします。個数、能力ごとのコスト、段階上限、能力の詳細は未確定です。

地域の状態は「未制圧」「掃討中」「安定」「緑化完了」とします。巣をすべて破壊すると新規スポーンが止まり、残存敵を排除すると安定します。多地域構成では、地域が安定すると次へ進めます。安定地域は隣接地域からの再侵攻でも壊されません。未制圧地域の敵は境界付近を攻撃し、長距離移動して安全な後方を襲う挙動は入れません。

安定後は、孤立した土地にも自動的に種が届く「遠距離の種の拡散」を働かせます。陸続きでないことや種資源の不足で最後のマスが残らないようにします。これは初期版から必要な完了保証です。自然拡張だけで植え替えや手動給水なしに、すべての緑化対象へ有限時間で到達できるようにします。敵を排除した後も緑化は続き、後方の地域を100％にしてから次へ進むことは求めません。拡散速度、所要時間、遊んでいる間の見せ方は未検証です。

緑化率は「発芽済み以上の対象マス数／緑化対象マス総数」。水面や建物などの対象外を分母に含めません。初期版では対象集合を固定し、破壊可能な建物は導入しません。端数の丸めで100％判定をしません。全地域の敵排除と緑化完了でゲームクリアです。

## 植物

### おたすけ植物

| 名称 | 姿と役割 | 自動化 |
|---|---|---|
| ガトリンガー | ひまわりのような姿。未播種の土地へ種を発射 | 近くの成熟植物から種を受け取り、重複播種を避ける |
| スプリンクラー | 逆さの水色のつぼみ。種や芽へ水をまく | 水辺では自動給水。遠方は手動補給や蓄雨植物で補助 |
| アーミー | 竹槍を持つ竹ゴーレム。自律攻撃系 | 防衛・探索・攻撃のモードを持つ。防衛では指定位置の近くを守る |
| ゲートルート | 穴の開いた球根。他のゲートルートへ移動 | 後期実装。地域間移動を短縮 |

おたすけ植物は倒されると消滅し、安全地帯へ復活させる方式は採用しません。おたすけたねを比較的得やすくして再建できるようにしますが、具体的な入手ペースは未確定です。

自動化の補給は近距離の受け渡しで始めます。初期版で複雑な配管・物流ゲームにはしません。

### 栽培植物

栽培植物は領域の性質を変える役割を持ちます。以下は採用済みの方向で、倍率と範囲は調整可能です。

| 植物 | 主な効果 | 初期版 |
|---|---|---|
| にんじん | 周囲の自然拡張を促進 | 実装 |
| キウイ | 回復する実を生産 | 実装 |
| クローバー | 周囲の種生産を増加 | 後期 |
| サボテン | 乾燥地でも定着し、緑化の起点になる | 後期 |
| ハス | 水上に育ち、水辺からの緑化範囲を広げる | 後期 |
| 蓄雨植物 | 大きな葉に雨水を蓄え、晴天時の水やりを補助 | 後期 |

同じ機能でも見た目の異なる植物を許し、好きな植物を増やす楽しさも残します。ハス導入時は、水上植物と土地の緑化率を別に扱うか、地域の対象定義を変更するかを明示して保存形式を更新します。

植物の設置に使う種の種類と量は植物ごとに異なります。数値の検討例（いずれも未確定の仮値）として、にんじんはカラフルたね1個で植え、成長後にたね1〜2個（種類未指定）とおたすけたね0〜1個を生産する案、スイカはカラフルたね5個で植え、カラフルたね5〜7個とおたすけたね1〜2個を生産する案があります。スイカは候補例で、キウイを置き換えません。おたすけ植物の設置費用例は、ガトリンガーがおたすけたね2個、アーミーが3個、より強力な候補のゴールドアーミーが10個です。種類や数値、初回収穫と周期収穫の量の差、頻度や確率は未確定です。

## 地形の意味

- 水辺：給水と栽培、自動化の拠点。
- 狭い道：アーミーによる前線維持に向く。
- 広い荒地：ガトリンガーと自然拡張が活躍。
- 死骸の周囲：一時的に成長しやすく、攻め込む足場になる。
- 乾燥地・湿地：対応する植物を追加する後期版で展開。

## 敵と死骸

巣から一定間隔でスポーンし、植物の領域を削り、敵領域を広げます。スポーン数には上限を設け、起動中の放置で敵が無限に蓄積しないようにします。

敵を倒すと種を得ます。後期版では珍しい種も入手します。種類によって死骸が残り、特に脊椎動物では多く残ります。死骸の周囲は植物の成長が促進され、死骸は時間とともに骨になり、砕けて消えます。初期版の敵はイノシシ型一種類とし、この循環を確認します。表現は小さなドット絵に収め、過度に生々しい方向へ拡張しません。

## スキル 後期実装

スキルシードで得たポイントを、パッシブ強化とアクティブスキルへ配分します。アクティブスキルは同時に2つまで装備できます。この装備数の上限はパッシブ強化には適用しません。通常の種資源や植物の希少な種とは別の仕組みです。

- どくガスふんしゃ：前方の敵へ継続ダメージ。
- かえんふんしゃ：大ダメージと植物への延焼。育てた緑を焼く判断を生む。
- 種バズーカ：通常の種資源を3個消費し、着弾点で爆発。

アクティブスキルの同時装備は2つ。安定地域で延焼した場合も、地域の安定は失わず、自動緑化で回復可能にします。延焼の範囲・終了条件は実装時に調整し、永久に緑化が完了しない状態を作りません。

## 時間と天気

日光と水分を独立した成長要因にします。晴れた昼は日光が強く、曇りと夜は弱い。雨と水やりは水分を増やし、水分は時間で減ります。成長速度の下限を正に保ち、通常植物は水不足や夜だけを理由に枯れません。

雨で発芽が進み、雨上がりの光で育つ変化を見せます。晴れた日は水やりの価値が上がり、雨の日は前線に集中しやすくなります。夜咲きや発光植物は後期版で追加し、必須素材を特定時刻にしか取れない設計は避けます。

初期版は起動中のみ進行し、メニュー・ポーズ中は世界時計、敵、成長、天候を止めます。全画面マップ導入時も、開いている間はこれらを止めます。再起動時に現実の経過時間分を加算しません。初期値では展望中も世界を止め、安心して景色を見られるようにします。

## アートと景観

輪郭線のないドット絵、ピクセルパーフェクトは必須です。主人公は16×16px程度、大きな敵は64×64px程度。通常画面は斜め見下ろし、空と遠景は展望地点で見せます。

展望画面は地域の緑化率、時間、天気を反映する専用の景観です。未制圧の荒地、緑の広がり、廃墟を覆う植物を同じ構図で比較できます。通常画面にも雲の影、雨、水面への空の映り込み、夕方の色を反映します。

## 初期版と製品版

初期版はWindows PC一人用、一地域、種まき・水やり、3種のおたすけ植物、にんじんとキウイ、敵1種と巣、死骸、昼夜と3天候、展望地点1つ、保存・再開、100％緑化までを含みます。

今後の多地域化では、中規模の複数地域をひとつの世界としてつなぎ、各地域は敵をすべて排除して安定させると次へ進める構成を方針とします。安定後も起動中は後方の緑化が続き、戻って完成した景観を楽しめます。100％緑化は次の地域へ進む条件にしません。主人公の強化は地域間で引き継ぎます。この方針の導入段階は未定です。

製品版では多地域、追加植物と敵、希少種、スキル、ゲートルート、夜の特殊植物、終了中の進行を追加します。世界の最終サイズ、地域数、総プレイ時間、販売方法、ゲームパッド対応は未確定です。初期版のためにこれらを先に決める必要はありません。
