# dotへ貼る開始プロンプト

## 1 既存アセット一覧HTML

```text
C:\godot\greenvader_asset_deliveries\assets の既存アセットを、完全IDとサムネイルが対応するオフラインHTML一覧にしてください。

指示書をPC側の利用可能な正式なファイル参照経路で読み、実行してください。
C:\godot\greenvader\docs\dot_blender\ruin_town_1000\01_THUMBNAIL_CATALOG.md

出力は C:\godot\greenvader_asset_deliveries\catalog\index.html です。検索・カテゴリ絞込み・画像拡大ができ、HTMLを直接開いて使えること。既存素材と旧台帳は変更しないこと。画像のない素材やIDの競合は隠さず表示してください。後からassets以下へ追加される素材も差分更新できる生成処理を残してください。

メインでできることはすべてメインで行い、必要なときだけLunaへ整理・転送・HTML更新をまとめて最小限委任して構いません。毎素材の委任は禁止です。旧案件の「累計最大1回」は今回の必要最小限というルールへ置き換えます。

実際にPCへ保存し、IDと画像の対応・リンク・件数・直開き動作を確認して報告してください。実行していない確認はNOT_RUNとしてください。
```

## 2 朽ちた町の追加1000件

```text
既存の町と素材を残し、長い年月で朽ちた町を組める追加アセット1000件を制作してください。植物は別作業待ちなので今回の対象外です。

以下の指示書を読み、実行してください。
C:\godot\greenvader\docs\dot_blender\ruin_town_1000\02_RUIN_ASSET_PRODUCTION.md
C:\godot\greenvader\docs\dot_blender\ruin_town_1000\01_THUMBNAIL_CATALOG.md

新規納品先は C:\godot\greenvader_asset_deliveries\assets\ruin_town_1000 です。既存ファイルを上書きせず、RUIN18の新規IDを使ってください。内訳は車両160、電柱/電線等120、倒壊構造160、路面140、瓦礫140、街路設備100、生活痕跡100、堆積/風化80です。色替えや回転だけで件数を増やさず、輪郭と壊れ方が低解像度で読める形にしてください。

モデル制作はメインがBlenderで行ってください。制作環境では各件を逐次保存し、PCへのまとめ保存は「前回の成功checkpointから実時間1時間以上」または「新規完成50件以上」の先に達した時点で行ってください。その同じタイミングで catalog\index.html も更新してください。終了・中断前は端数でも最後に保存・更新します。

メインでできることはすべてメインで行い、PC保存・照合・HTML更新に必要な場合のみLunaへまとめて委任して構いません。毎checkpointの自動委任は不要です。旧案件の累計1回上限は適用せず、必要最小限としてください。

各ロットのユーザー承認待ちは不要です。既存一覧HTMLがまだなければ指示書01で初版を作ってから制作を進めてください。最後に1000件とは別の3配置見本も提出してください。PC確認済みとHTML反映済みを区別し、利用枠などで止まる場合は未完と再開手順を正直に残してください。
```
