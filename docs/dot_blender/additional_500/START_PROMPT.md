グリーンベーダー用素材の追加制作をお願いします。既存素材をGodotの低解像度画面で確認したところ、種類は十分揃っているため、今回は次の改善に集中して**約500件を追加生成**してください。

- 樹木：幹や枝に葉が点在する印象を減らし、中サイズの葉群が重なる豊かな樹冠と、その間の隙間を作る。
- ツタ：曲がる幹に密な葉群を追加し、成熟時の局所的な茂りを作る。壁全体を埋めず、コケと合わせても壁の約50%以上を見せる。
- コケ：均一な緑色の板に見せず、破れた縁、地肌の抜け、大きめの色のまとまりを持つ薄膜にする。
- 下草と接地部品：短草・背高草・低木、壁際の土だまり・落ち葉・薄く散った瓦礫などを作り、建物と地面をなじませる。
- 建物と付属品：細かな点ノイズを整理した建物を新規生成し、窓枠・雨樋・外壁配管・手すりを独立して使えるようにする。
