# グリーンベーダー Blender素材制作の引き渡し

新しいdotのメインエージェントへ渡す制作資料です。現在の低解像度3Dの見た目に合う素材をBlenderで作り、ゲーム側へ渡せる形にします。この資料作成時点では、以下の240候補を制作したことにはなりません。

1. [制作指示書](INSTRUCTIONS.md)：ツール、費用、造形、寸法、植生接続、書き出し、確認の基準。
2. [240件の制作候補](ASSET_CATALOG.md)：一意のID、形の違い、用途、仮寸法。
3. [開始プロンプト](START_PROMPT.md)：新しいdotへそのまま貼る文章。

新しいdotにこの3ファイルを渡し、開始プロンプトの本文を貼ってください。ローカルパスを読めない環境ではファイルを添付します。画像を渡せる場合は、既存小マップの[最大成長例](../../evidence/building-model/self/model_growth135_ui_1920.png)と[低い太陽](../../evidence/building-model/self/elevation15_ui_1920.png)も参考にします。

最初は候補数を確認し、代表6件で作風と受け渡し方式を確かめます。240件を一度に作り始める指示ではありません。代表6件のユーザー確認後、12件以下の小ロットで残りを進めます。既定ではサブエージェント0回、例外でも案件全体でLunaを1回まで、記録整理に限ります。

| 分類 | 候補数 |
|---|---:|
| 建物 | 60 |
| ツタ | 30 |
| コケ | 20 |
| 樹木 | 40 |
| 地面と水たまり | 40 |
| 景観小物 | 50 |
| 合計 | **240** |

既存ゲームのモデル読み込み確認は[建物モデルガイド](../BUILDING_MODEL_GUIDE.md)を参照。新dot側ではBlenderでの制作・確認までを担当し、Godot実機での採用判定はゲーム側で行います。
