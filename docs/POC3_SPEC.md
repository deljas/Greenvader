# PoC3 仕様正本

更新日: 2026-10-24

この文書はPoC3の合意済み仕様を記録します。現時点では一部の論点のみ合意済みで、PoC3全体の範囲・実装・検証完了を示すものではありません。PoC2からの比較基準は[第二弾仕様正本](POC2_SPEC.md)です。PoC2の記述は過去版として保持し、ユーザーがPoC3向けに明示して合意した変更だけを本書で上書きします。未決事項や助手の提案を確定仕様として扱いません。

PoC3のソース管理・起動入口の運用は[ソース管理方針](SOURCE_MANAGEMENT.md)を参照してください。

## 通常画面での敵・巣の表示

- **合意日・決定者:** 2026-10-24、ユーザー。
- 通常画面のカメラ内にいる敵、固定巣、動く親玉は、主人公との距離による視界判定で非表示にしません。
- 建物による遮蔽は別の表示処理で扱います。遮蔽物越しにすべてを表示する仕様は合意していません。
- 敵や巣が画面に表示されたことだけを理由に巣を起動しません。接近・緑化による既存の起動条件を維持します。
- マップ上の敵・巣の情報公開条件は、この合意の対象外であり、別途決めます。

この方針は未実装です。試遊で報告された非表示現象の再現も未実施です。原因候補と実施範囲は[POC3-VISIBILITY作業票](../tasks/POC3_VISIBILITY.md)を参照してください。
