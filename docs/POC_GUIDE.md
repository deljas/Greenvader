## 起動

- 当時は `launchers/run_poc.bat` から `res://scenes/poc.tscn` を起動していました。この専用入口は削除済みで、保全タグ `poc2-before-poc3` から復元できます。現行の通常入口 [run_game.bat](../run_game.bat) はPoC2を起動し、`project.godot` の `main_scene` は `scenes/poc2.tscn` です。

  - `--debug-weather` は開発用。1/2/3/0キーによる天候切替は、この起動時だけ有効です。

## 操作

| 操作 | 内容 |
|---|---|
| WASD・矢印 | 移動（画面の方向基準、斜めは正規化）。移動速度は4.8m/s |
| 左クリック | 種をまく（選択中の植物：通常／にんじん／キウイ）。発射は入力から66ms後。おたすけ植物の設置モード中は設置 |
| 右クリック | 水をまく。発射は入力から400ms後。おたすけ植物の設置モード中は設置モードを終了 |
| Tab・ホイール | 植物の切替 |
| Q | おたすけ植物の設置モード（オフ→ガトリンガー→スプリンクラー→アーミー→オフ） |
| E | 調べる。近くでは見晴らし台の展望、おたすけ植物の持ち上げ |
| M | 音のミュート切替（設定は user://poc_ui_settings.json） |

| F3 | 倍速 |
| F5 | 保存 |

### 種・水の発射表示（4方向の試遊用仮組込み、2026-10-20）

- 左クリックで種動作を開始し、66ms後に種を発射、400msで通常表示へ戻ります。右クリックの水は400ms溜めて発射し、800msで戻ります。種は全方向・全コマ通常の目、水は正面v3の表情と動きを維持します。プレイヤーは24×36px、anchor(12,34)、down/left/right/upです。左右は反転せず、背面は顔なしです。
- 発射中も表示方向はマウス照準に追従します。弾は入力時に決まった地面位置の方向へ飛びます。移動は継続できます。葉間の表示出口は左向きx=11、他方向x=12（y=14）です。これは弾の表示位置に使い、論理上の発射起点は変えません。
- 入力時に地点を判定し、発射時に資源・弾上限などの条件を再確認します。開始/再確認で条件を満たさなければ発射せず通常表示へ戻り、費用もかかりません。通常種/水は発射時に費用を減算します。栽培種は発射時に予約し、種袋の消費は弾の着地成功時です。溜め中の追加クリックは受け付けず、時間をやり直しません。発射後の戻り動作は次のクリックで中断できます。停止メニュー・ポーズ・展望中は時間が止まり、ロード/新規開始/戦闘不能では未発射動作を破棄します。溜め途中の状態は保存されません。
- この4方向発射は試遊用仮組込みです。種/水の資源量、弾速・範囲、当たり判定やゲーム内水範囲は変更していません。親は素材制作とゲーム組込みを限定技術受入しました。独立検証は12 PASS / 0 FAIL / 4 NOT_RUNです。物理マウス/キーボード、連続プレイの実速感や楽しさ、最終美術評価は未確認です。画面比較は連続操作の録画ではありません。現行証拠は[SPR-01検証記録](VALIDATION.md#spr-01-発射4方向v1のゲーム仮組込み2026-10-20)を参照してください。

## 遊びの流れ

1. 安全地帯から始まります（初期安定、初期緑化484セル、種の供給源2）。
2. 戦闘地域「廃街区」には巣が3つあります。
3. 巣をすべて壊すと新しい敵の出現が止まります。残りの敵を排除すると地域が安定します。
4. 安定後、遠距離の種の拡散で孤立した島を含めて緑化が進みます。緑化対象は9464セルです（建物・水・屋内の封鎖は分母に含みません。舗装は対象）。
5. 100％に達すると「★緑化完了」が表示されます。

- 時間: 1日=ゲーム内600秒、開始は8:00。北は画面の上、太陽は東→南→西へ動きます。
- 100％までの時間: 安定後の目安は約5.75分（ゲーム内時間。F3の倍速を使えます）。作り込み段階で約13分から短縮しました。延長はしていません。
- HUD: 種・水・HP・選択中の植物・緑化率、地域名・状態・残りの巣と敵、時刻。2行目に天気を表示します。右下は内部の緑化率です（端数切捨て。99％を100％とは表示しません）。

## 作り込み段階で追加した遊び

### おたすけ植物（Q）

- Qで設置モードに入り、オフ→ガトリンガー→スプリンクラー→アーミー→オフの順に切り替わります。設置モード中は左クリックで設置、右クリックで設置モードを終了します。
- 設置には「おたすけたね」を使います。費用は、ガトリンガー2、スプリンクラー2、アーミー3です。
- 設置条件: 4×4セルがすべて成熟・非占有・歩行可・巣でないこと、プレイヤーから射程4.0m以内であること。上限は6体です。
- 近くのおたすけ植物にEを押すと持ち上げられ、もう一度設置すると置き直せます（費用なし）。
- おたすけたねは、成熟した栽培植物（にんじん・キウイ）からまれに落ちるほか、巣を壊したときの報酬です。
- 3種の働き:
  - ガトリンガー: 効果半径6.0m。近くの成熟植物から種を受け取り、空き地へ撃って播種します。
  - スプリンクラー: 水辺に置くと補給なしで給水します。水辺以外では内部の在庫を使い、プレイヤーが近づくと補給します。
  - アーミー: 置いた位置の半径4.0m内の敵を迎撃します。その外へは追いかけません。
- おたすけ植物はイノシシに壊されることがあり、HPが0になると消滅します。

### 天候

- 晴れ・曇り・雨が、ゲーム内時計から決まります。
- 晴れの昼は日光で成長が速くなります。雨は範囲全体の水分を上げます。曇りや夜でも成長は止まりません。
- HUDの2行目に天気を表示します。
- 開発用の1/2/3/0キーは `--debug-weather` で起動したときだけ有効です。

### 見晴らし台

- 安全地帯の北西角にあります。近くでEを押すと世界を止めて街全体を見渡し、緑化率・時刻・天気を表示します。
- Esc または Eで戻ります。展望中は時間が進まず、保存はできません。

### 音と表示

- 音は外部素材を使わず、コードで生成しています。操作音8種（種・水・設置・拾得・命中・巣破壊・地域安定・全緑化）と環境音（風、雨、緑化率に応じた小鳥）があります。
- Mで音をミュートします（設定は user://poc_ui_settings.json）。
- 主人公の足元に淡い円盤が付き、夜は主人公の周囲が弱く照らされます。イノシシの足元には赤橙の楕円が付きます。夜だけ点く街灯が10基あります。
- 水面の反射を強化しました。

### 移動と建物

- 移動速度は4.8m/s（従来の2倍）です。
- 建物は回転で向きを変えます（左右反転は使いません）。

## 保存と再開

- 保存先: `user://poc_saves/slot.json` と直前の `slot.bak.json`。Windowsでは `%APPDATA%/Godot/app_userdata/グリーンベーダー/poc_saves/` です。
- 保存は手動の1枠と直前のバックアップです。自動保存はありません。
- 保存形式は format_version 2 です。POC-08の旧版（v1）は版違いとして読込を拒否し、案内を表示します。旧版のファイルは変更しません。
- おたすけ植物、おたすけたね、天候も保存します。
- 版やマップが違う、破損している、範囲外の値がある場合は読込を拒否し、日本語で理由を表示します。現在の状態は壊しません。値を黙って補正することはしません。
- 飛翔中の弾は保存されず消えます。消費した種と予約中の種は返却されます（種が上限まで入っているときは上限で切られます）。
- 展望中は保存できません。
- 終了中は時間が進みません。

## 解像度

- 内部画面は640×360固定です。ウィンドウは固定せず、nearestの整数倍表示と余白で扱います。非整数縮小では埋めません。
- 1080p表示では3倍の整数拡大（nearest）です。旧960×540切替は過去のPoC設定です。
- 輪郭線はなく、ピクセルの見え方を保ちます。

## 主人公の歩行

- 現在の主人公の歩行は、ユーザーが採用した通常歩行v2です（[素材](../assets/concepts/spr01/walk-normal-v2/preview.gif)）。跳ねずに足を交互に動かし、胴・顔の小さな上下変位と手・葉の動きを付けます。
- 試作比較時のF6/右上ボタンによる跳ね歩き切替と比較案内は、通常歩行v2の採用仕上げでゲームから除去しました。歩行比較用の操作はありません。

## 既知の限界と未確認事項

- **NOT_RUN（未確認）**: 物理キーボード・マウス（OSを経由する入力）、run_poc.bat からの実起動の窓での描画、実際の1920×1080窓や非整数の窓、実速度での長時間プレイ、低スペック機や他のGPU、大規模な負荷、Windows書き出し、実音の聴取。
- **楽しさ・テンポ・美術の評価はユーザーの判断です。** AIは代行していません。
- 夜間や建物越しの透過では主人公が小さく低コントラストになり、夜の640ではかなり見分けにくいです。足元の円盤と夜の局所光、敵の足元マーカーを追加しましたが、統合時点の所見として見分けにくさは残ります（夜の草地では足元の円盤が断片的）。
- 水面の反射は作り込みで強化しましたが、評価は未確認です（前段の所見は鏡像が弱め。`water.reflection_strength` などで調整可能）。
- 夜の街灯は10基を実装しました（夜だけ点灯）。
- 仮の2D人間と仮のイノシシの表示です。960用の人間は32×48の原画を0.75倍に縮小した近似です。HUDは既定フォントです。
- 0.4mのセル単位のため、確実に通れるのは壁面間約1.2m以上です（主な導線は1.6m以上で配置）。屋内・階段・高低差は対象外です。
- 壁越しの植付は着弾点を基準に判定します。水の散布は壁の反対側の水分を上げることがあります（植付・緑化率には影響しません）。
- 終了時にObjectDBのリーク警告が出ます（機能には影響しません）。
- 作り込みの統合確認で得た所見（ユーザー確認事項）:
  - 種の供給源が遅く、補給待ちが長い（約281s）。
  - おたすけたねは巣の報酬が中心です。
  - 前線のおたすけ植物は壊されやすいです。
  - ガトリンガーの前線効果は、イノシシの食害で頭打ちになります。
  - 統合の1回ではスプリンクラーの給水とアーミーの撃破は0でした。
  - 主人公と敵が小さく、見分けにくいです。
  - 夜の草むらの種が読みにくいです。晴れの昼の雲の影は弱いです。
  - 展望パネルが北の角に一部重なります（640）。
  - 960の1フレーム17.2msは1回の測定です。

## PoCの範囲外

- 作り込み段階で、おたすけ植物（PoC側の部品）、晴れ・曇り・雨の天候、見晴らし台、音の基本を追加しました。P3〜P5の残要件（本格的な天候の仕上げ、保存の仕上げ、配布ビルド、総合検証）は含みません。
- スキル・強化、ミニマップ・全体マップ（全画面マップ・ミニマップは範囲外）、マップエディタ、多地域、配布ビルドは未着手です。
- 本PoCは製品完成ではありません。次の範囲はユーザーが決めます。
