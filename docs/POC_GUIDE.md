# 3DクォータービューPoC 操作書

更新日: 2026-10-18。対象は POC-01〜09 の3DクォータービューPoC（承認済み事実: [evidence/poc/09/approved_facts.md](../evidence/poc/09/approved_facts.md)）。PoCは製品版ではなく、P3〜P5の全体や配布ビルドを含みません。

## 起動

- [launchers/run_poc.bat](../launchers/run_poc.bat) を実行すると `res://scenes/poc.tscn` が開き、タイトルから始まります。
- 通常入口の [run_game.bat](../run_game.bat)（旧ゲーム）と project.godot の main_scene（旧 scenes/main.tscn）は変更していません。
- 旧fixtureの引数（検証用）: run_poc.bat は引数を転送しないため、Godotをコマンドラインで起動し、シーン指定の後ろに次の引数を付けます。
  - `-- --fixture=02`、`-- --fixture=04`、`-- --combat`、`-- --bare`
  - `--debug-refill` は開発用。F9のデバッグ補給はこの起動時だけ有効です。

## タイトル

- 新規開始
- 続きから（保存がないと無効）
- バックアップから続ける（バックアップがあるときだけ表示）
- 操作説明

## 操作

| 操作 | 内容 |
|---|---|
| WASD・矢印 | 移動（画面の方向基準、斜めは正規化） |
| 左クリック | 種をまく（選択中の植物：通常／にんじん／キウイ） |
| 右クリック | 水をまく |
| Tab・ホイール | 植物の切替 |
| E | 調べる |
| Esc | ポーズメニュー（再開／保存／読込／バックアップから読込／操作説明／タイトルへ） |
| F2または右上ボタン | 解像度を 640×360 ⇄ 960×540 で切替 |
| F3 | 倍速 |
| F5 | 保存 |

## 遊びの流れ

1. 安全地帯から始まります（初期安定、初期緑化484セル、種の供給源2）。
2. 戦闘地域「廃街区」には巣が3つあります。
3. 巣をすべて壊すと新しい敵の出現が止まります。残りの敵を排除すると地域が安定します。
4. 安定後、遠距離の種の拡散で孤立した島を含めて緑化が進みます。緑化対象は9464セルです（建物・水・屋内の封鎖は分母に含みません。舗装は対象）。
5. 100％に達すると「★緑化完了」が表示されます。

- 時間: 1日=ゲーム内600秒、開始は8:00。北は画面の上、太陽は東→南→西へ動きます。
- 100％までの時間は、安定後およそ10〜13分（ゲーム内時間。F3の倍速を使えます）。延長はしていません。
- HUD: 種・水・HP・選択中の植物・緑化率、地域名・状態・残りの巣と敵、時刻。右下は内部の緑化率です（端数切捨て。99％を100％とは表示しません）。

## 保存と再開

- 保存先: `user://poc_saves/slot.json` と直前の `slot.bak.json`。Windowsでは `%APPDATA%/Godot/app_userdata/グリーンベーダー/poc_saves/` です。
- 保存は手動の1枠と直前のバックアップです。自動保存はありません。
- 旧セーブは読まず、変更もしません。
- 版やマップが違う、破損している、範囲外の値がある場合は読込を拒否し、日本語で理由を表示します。現在の状態は壊しません。値を黙って補正することはしません。
- 飛翔中の弾は保存されず消えます。消費した種と予約中の種は返却されます（種が上限まで入っているときは上限で切られます）。
- 終了中は時間が進みません。

## 解像度

- F2または右上ボタンで 640×360 と 960×540 を切替えます。カメラの視野（約18.5m）は変わりません。
- 1080p表示では 640 は3倍、960 は2倍の整数拡大（nearest）です。
- 輪郭線はなく、ピクセルの見え方を保ちます。

## 既知の限界と未確認事項

- **NOT_RUN（未確認）**: 物理キーボード・マウス（OSを経由する入力）、run_poc.bat からの実起動の窓での描画、実際の1920×1080窓や非整数の窓、実速度での長時間プレイ、低スペック機や他のGPU、大規模な負荷、Windows書き出し。
- **楽しさ・テンポ・美術の評価はユーザーの判断です。** AIは代行していません。
- 夜間や建物越しの透過では主人公が小さく低コントラストになり、夜の640ではかなり見分けにくいです。
- 水面の反射は鏡像が弱めです（`water.reflection_strength` などで調整可能）。夜の街灯は未実装です。
- 仮の2D人間と仮のイノシシの表示です。960用の人間は32×48の原画を0.75倍に縮小した近似です。HUDは既定フォントです。
- 0.4mのセル単位のため、確実に通れるのは壁面間約1.2m以上です（主な導線は1.6m以上で配置）。屋内・階段・高低差は対象外です。
- 壁越しの植付は着弾点を基準に判定します。水の散布は壁の反対側の水分を上げることがあります（植付・緑化率には影響しません）。
- 終了時にObjectDBのリーク警告が出ます（機能には影響しません）。

## PoCの範囲外

- P3（おたすけ植物と自動補給）、P4（本格的な天候・昼夜の仕上げ・展望・音）、P5（保存の仕上げ・配布ビルド・総合検証）の残要件は含みません。
- おたすけ植物、本格天候、スキル・強化、ミニマップ・全体マップ、マップエディタ、多地域、配布ビルドは未着手です。
- 本PoCは製品完成ではありません。次の範囲はユーザーが決めます。
