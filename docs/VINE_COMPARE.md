# 旧ツタと納品ツタの比較ツール

このツールは、既存の小マップ用ツタと外部納品されたVINモデルを、同じ低解像度画面で見比べるための専用試作です。通常ゲームの緑化状態や保存データは変更しません。

## 起動

[`run_vine_compare.bat`](../launchers/labs/run_vine_compare.bat)を起動します。納品フォルダ`C:/godot/greenvader_asset_deliveries/assets/vines`が必要です。別の場所へ置いた場合は、画面上部のパス欄にそのフォルダを入力して「再読込」を押してください。metadataとGLBから一覧を作り直します。失敗したID/パスは画面に理由を表示し、直前の表示を保持します。

## 操作

- 左側の既存ツタ密度は「旧:小マップ疎密」が初期値です。「旧:lab密度」で既存lab相当へ切り替えます。
- 右側の納品ツタは一覧、「前」「次」、またはID入力（`007` / `VIN-007`）から選びます。エラー後は正しいIDを選ぶか、フォルダを再読込してください。
- 下の同期成長sliderまたは0/25/50/75/100%ボタンで両側を同じ値にします。「再生」は現在の値から続き、100%から再生した場合だけ0%へ戻ります。0%から100%までの全長は約16秒です。「停止」でその場に留まり、「先頭へ」は停止して0%へ戻します。IDを変えても現在の値を保ちます。
- 右側の途中段階は、納品metadataとmesh経路から根・親幹・枝・葉の順を推定し、元の三角形を段階的に表示します。推定した順序は成長アニメーションの仕様、経過時間、被覆面積の比較を表しません。葉だけのモデルでは小さなポリゴンから現れる場合があります。
- 受け面は「自動」「共通の窓壁」「受け面なし」を選べます。自動は床用の部品に壁を置かず、壁用・張出し・根元の一部を簡易な面で見せます。すべての複合形状を再現するものではありません。
- 起動時の視野はcamera.size 6.8です。「＋」「−」で共通視野を拡大・縮小し、「18.5m」で小マップ相当の広い視野へ切り替えます。方位と仰角sliderは太陽光の方向を調整します。

## 比較上の注意

描画基準は640×360、正投影30°/45°、整数nearest拡大です。左右は同じ画面・照明・視野を使います。納品モデルの元scaleと100%のmesh・材質を維持し、左右に並べるための中心位置だけを調整します。比較画像は用途や縮尺が異なるモデルを並べるためのもので、地面格子やゲーム内サイズの適合を保証しません。

成長100%では納品元のmeshと材質をそのまま表示します。0〜100%の間は比較用の推定表示です。植物の実時間成長、地面緑化率、通常ゲームのツタ配置・成長保存との連携はありません。ツタ63件の読込試験は行っていますが、全モデルの表示・全角度・性能を検証したものではありません。見た目の最終評価はユーザーが行います。
