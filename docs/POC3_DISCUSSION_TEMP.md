# PoC3 壁打ち用・一時論点リスト

更新日: 2026-10-24

## 用途と削除条件

PoC2の試遊レビューをもとに、PoC3で決めることを一件ずつ壁打ちするための作業用一覧です。ここにある提案はすべて討議のたたき台であり、ユーザーが合意するまではPoC3の仕様ではありません。既存PoC2仕様は過去版の記録として保持し、PoC3方針で上書きしません。

この一覧は、すべての論点について採用・不採用・後送りが合意され、後送りには理由と引き継ぎ先が記録され、決定事項と実装に残る作業が正式資料または作業票へ転記された後に削除します。削除前に、この文書を参照するリンクも掃除します。壁打ち中の一時文書の更新は、正式な仕様決定・実装完了・不具合検証完了を意味しません。

## 進め方について合意済みのこと

- 通常ゲームの起動batは1本にし、細かい機能単位の確認が必要な場合だけ専用batを追加する。
- Gitコミットを適宜行う。リモートへのpushはユーザーが行う。
- PoC3の論点を順番に壁打ちし、合意事項をその都度、適切な正式資料へ記録する。
- 今回は一時リストの作成まで。論点を一括決定したり、ゲームを変更したりしない。
- 旧PoCや旧版ファイルの削除・置換はこのリスト作成に含めない。Git上の履歴と既存の保全方針を確認して別途扱う。

## 論点

各項目の「状態」は討議の進み具合です。「参照用の提案」は採用済み仕様ではありません。正式資料候補は移記先の目安で、合意内容に応じて親が確定します。
