# 小街区・歩行・昼夜の試作

この専用labは、納品された建物や小物を置いた小街区を歩き、昼夜の変化と水面反射を確かめるための技術試作です。主人公は既存の仮人間spriteで、完成アートではありません。

## 起動と操作

[`run_town_lab.bat`](../launchers/labs/run_town_lab.bat)から起動します。WASDまたは矢印キーで画面方向へ歩きます。斜め移動は正規化されています。`F`で全景と主人公追従を切り替え、画面上部の「＋」「−」ボタンでズーム、`R`で開始地点へ戻ります。水たまりの上も歩けます。

画面上部の時刻sliderは0〜24時です。ボタンで朝7時、昼12時、夕17時、夜22時に切り替えます。`再生`/`停止`で時間を進め、速度は×0.25、×1、×4から選べます。初期速度は×1で、1日を約120秒で一周します。24時と0時は連続して扱われます。

方位表示は北が画面上、東が右、南が下、西が左です。太陽は6時頃に東から昇り、正午に南側で最大仰角55°となり、18時頃に西へ沈みます。夜間は太陽光が無効になり、近似月光と街灯が点灯します。

## この試作で確認できること

50m四方程度の街区に建物7棟、複数の小物、樹木、水たまり4箇所を元モデルの縮尺で配置しています。建物・大きな物体・街区境界には簡易衝突があります。水面はカメラ移動に追従する低解像度反射を使い、昼は太陽、夜は局所灯による影を反映する近似表現です。

描画は640×360を整数nearestで拡大し、正投影30°/45°と硬い影を使います。代表画像は[朝](../evidence/town-lab/self/morning_overview_ui_1920.png)、[昼](../evidence/town-lab/self/noon_overview_ui_1920.png)、[夕](../evidence/town-lab/self/evening_overview_ui_1920.png)、[夜](../evidence/town-lab/self/night_overview_ui_1920.png)です。

## 限界

これは通常ゲームとは独立した試作です。植物の新規制作や成長、戦闘、保存、本編への統合は行いません。衝突は街区の屋外を歩くための簡易形状で、建物内部、階段、すべての隅での通行を保証しません。人影は主街灯1灯に追従する近似で、水面の夜間受影も厳密な多灯照明ではありません。季節・緯度に基づく天文学的な昼夜計算、全角度での性能、ユーザーの最終美術評価は対象外です。
