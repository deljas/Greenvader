# グリーンベーダー 開発引き継ぎ資料

作成日：2026年10月14日。版：1.0。

小さな花が荒廃した地球を緑で覆う、2Dアクション・放置ゲームをGodotで開発するための資料です。まず一地域の体験版を完成させ、遊びと絵作りを確かめてから世界を広げます。この資料の作成時点では、ゲームの実装・動作検証は開始していません。

## 読む順序

1. [企画書](01_GAME_DESIGN.md)：目標とゲームルール、初期版と将来版の範囲。
2. [技術方針とアート仕様](02_TECH_AND_ART.md)：実装構成、表示、保存、検証。
3. [段階別の開発計画](03_DEVELOPMENT_PLAN.md)：各段階の成果と合格条件。
4. [自律開発の指示書](04_AGENT_BRIEF.md)：AIの裁量、進め方、引き継ぎ、開始プロンプト。
5. [モデル選定メモ](05_MODEL_SELECTION.md)：AstraとOpus 5.5の使い分け。

## 決定の扱い

- **確定**：会話で採用された方向。AIの都合で変更・削除しない。
- **実装初期値**：未指定の詳細を進めるため、この資料で置いた仮の値・方式。検証し、理由を記録して調整できる。
- **後期実装**：採用済みだが最初の体験版には含めない。未実装を理由に企画から削除しない。
- **未確定**：最終的な商品仕様。初期版に不要なら質問で開発を止めない。

最新のユーザー指示を最優先し、その変更を関係する資料へ反映します。文書間に矛盾があれば、確定事項を維持しながら解消します。

## 確定事項の要約

- Godot、型注釈付きGDScript、Windows PC、オフライン一人用、キーボードとマウス。
- プレイヤーが前線を開拓し、植物が後方の緑化と維持を自動化する。
- 敵は未制圧地域の境界付近を攻める。巣を制圧し残存敵を排除した地域は安定する。
- 植物領域は自然拡張する。敵を根絶やしにすれば、追加操作なしで緑化対象を100％にできる。
- 初期版の放置進行は起動中のみ。アプリ終了中の進行は後期実装。
- 美しい侵略。かわいい主人公と、動物を排除して緑に覆い尽くす不穏さを両立する。
- 輪郭線のないドット絵。ピクセルパーフェクト必須。柔らかい光・霧・発光は許すが、元絵をぼかしたり歪ませない。
- 昼夜、晴れ・曇り・雨。日光と水分を別々に成長へ反映する。
- 通常画面は斜め見下ろし。空は展望地点の専用景観で見せる。

## 引き渡し方法

この資料一式を開発リポジトリの `docs/green-invader/` に置き、04_AGENT_BRIEF.md末尾の開始プロンプトを開発AIに渡してください。既存の指示ファイルがある場合は上書きせず、この資料への参照を追加します。モデルやサービスが変わっても、進捗・決定・検証記録をリポジトリに残せば引き継げます。

最初の開発依頼の対象は03のP0からP5までです。P6以降は製品版への拡張計画であり、自動的に着手する範囲ではありません。
