# グリーンベーダー 段階別の開発計画

更新: 2026-10-18。現在の実行計画は下記のPOC-01〜09です。旧P0〜P5の順次実行、旧P2-06からの自動再開は置き換えました。今回Codexが行うのは計画と着手資料の更新のみで、実装はClaudeが個別作業票を取得して進めます。日数・完成時刻は未見積もりです。

## 今回の到達点

小さな一地域で「種まき・給水 → 戦闘と巣の破壊 → 地域安定 → 入力なしで孤立地込み100％緑化」を遊べるPoCにします。Godotの3D地形/建物と2D仮キャラクターを固定クォータービューで表示し、640×360と960×540を切替可能にします。この範囲と小街区制作はユーザーが2026-10-18に選択済みです。

現在の町labは景観・歩行・昼夜試作で、敵/資源/成長の統合済みゲームではありません。P1とP2-01〜05には再利用できるロジックがあり、greening_mapには一部の世界状態/成長接続があります。これらを一つのPoCへ接続し、二重のシミュレーションや試作用の無限補給を本編へ持ち込まないことを優先します。

## 表示と遊びの境界

- 解像度は640×360/960×540の両方を正式なPoC設定とし、初期値は現行試作に合わせ640×360（調整可能）。同じ視野・物体寸法を保ち、1080pでは3倍/2倍。その他の窓は整数拡大と余白で扱い、非整数縮小で埋めない。
- 背景は3D用材質と動的な光/影。傾斜面上のテクスチャ画素と画面画素の1対1対応は要求せず、最終低解像度描画をnearest整数倍にする。全面ぼかし・輪郭線は不可。
- キャラクター/敵は仮2Dスプライトでよい。主人公の完成デザイン、モデル全件の美術磨き込みは不要。
- 屋外の平地を初期範囲とし、屋内探索・高低差移動・橋の上下通行・自由カメラ回転は後段。配置形式は今後拡張できるようにするが、汎用エディタを先に作らない。
- 内部緑化率と見かけの被覆は分離。土は茂り、舗装は割れ目中心、建物は壁の約半分を残す。建物/水面等の緑化対象外は分母から除き、地形別表示のために内部率を改変しない。
- 北=画面上、太陽は東→南→西。昼夜と成長を同じゲーム時計に接続。時刻/天気だけで成長を止めず、終了中の進行はなし。
- 地形セル0.4mや約50m四方・5〜8棟は接続/配置の初期値。旧512×512地域や30〜60分の体験版目安はこの小PoCの必須条件にしない。テンポの最終評価はユーザーが行う。

## PoC後に残すもの

P3のおたすけ植物と補給/移動指示、本格的な晴曇雨、展望、音、ミニマップ/全体マップ、スキルシード/強化、3種類の種と運搬役は後段の設計・実装範囲を決めてから進めます。企画から削除しません。P3の旧設置案と企画書の移動命令/消滅再建案の整合も着手時に必要です。

## ClaudeとCodexの並行作業

ClaudeはPOC-01から依存順に実装し、各票で親が具体的な編集予約を取ります。Codexの今回の予約は計画文書だけで、完了後に解除します。ユーザーが別途依頼する素材確認・dot向け指示書等は、コード/importに触れず分離すれば並行可能です。

同じ共有ツリーなので、ゲームコード、project.godot、素材の取込み/import、実行中Godot、共通文書、Git indexは担当を一つにします。ファイルを分けただけでGodotを同時起動しないこと。Claudeが取り込むアセットは納品の保存済み版を固定し、dotの作業途中フォルダを参照しません。今回Claudeの起動・送信・コード変更は行いません。

## 過去の段階計画と後期要件の参照

以下のP0〜P5は従来の成果/受入条件を保存した参照資料です。新しい実行列ではありません。旧画面の条件は上の移管表を優先し、ゲームの保証は対応するPoC票や後期票へ引き継ぎます。

## P0 環境と画面の基準

実施：既存ファイルと利用可能ツールを調査し、Godotの版を固定。プロジェクト、入力、世界描画とカメラ、最低限のUIを作る。主人公と地形、敵、水辺、植物の仮素材を配置し、晴れ・雨・夜の見た目を試す。この段階の天候は見た目だけでよい。

成果：起動する画面、移動と照準、3条件の比較画像、バージョンと実行手順、アート基準、決定記録。

合格条件：

- 画面を開き、操作できる。
- 元絵に輪郭線がなく、画素格子が揃っている。
- 基準640×360を採用する場合、1280×720、1920×1080、1366×768で整数拡大と余白が正しく機能する。基準変更時は対応する試験値を記録する。
- カメラ移動と斜め移動でドットがにじまない。
- 夜と雨でも主人公・敵・弾の仮表示を判別できる。

美術上の感想待ちだけで開発を止めず、技術条件を満たす暫定基準でP1へ進む。ユーザーが修正を指定した場合は反映する。

## P1 手動開拓の循環

実施：種まき、水やり、発芽と成熟、種生産、水辺の給水、自然拡張、にんじんとキウイ、緑化率を実装。小さな安全地帯と荒地を置く。

成果：敵のいない地域を、資源を循環させて緑化できるビルド。

合格条件：

- 種が着弾し、芽を出し、成熟して次の種を生む。
- 水やりで成長が速くなる。水なしでも成長する。
- 種ゼロ、水ゼロでも回復して開拓を再開できる。
- 成熟領域から自然に緑が広がる。
- にんじんの効果とキウイの回復を確認できる。
- 緑化対象外への発射で不正な成長やカウント増加が起きない。
- ポーズ中に資源や成長が進まない。

この段階で操作の気持ちよさと成長時間を短いプレイで確認し、調整値を記録する。

## P2 敵と地域制圧

実施：イノシシ型の敵、巣、スポーン上限、種による攻撃、敵の侵攻、死骸と肥沃効果、戦闘不能と復帰、地域状態の遷移を追加。

成果：敵と領域を奪い合い、巣を破壊して安定地域を得られるビルド。

合格条件：

- 巣が存在する間だけ敵が上限付きで出現する。
- 敵が境界の植物領域を削る。
- 死骸が成長を助け、骨を経て消える。
- 巣破壊後は新規スポーンが止まり、残敵排除後に地域が安定する。
- 安定地域へ敵が再侵入しない。検証用の隣接敵地域でも確認する。
- 主人公の復帰で地域状態が巻き戻らない。
- 孤立した緑化対象を含む検証マップで、安定後に入力なしで厳密に100％になる。

緑化完了試験には固定マップと固定乱数を使い、設定から求めた完了上限時間以内に全対象が緑化することを確認する。単に時間を延ばして失敗を隠さない。

## P3 後方の自動化

実施：ガトリンガー、スプリンクラー、アーミー、自動補給、移設、効果範囲の表示を追加。水辺・狭い道・広い荒地の使い分けを地域に組み込む。

成果：プレイヤーが前線に集中できる一地域のゲームループ。

合格条件：

- ガトリンガーが近隣の成熟植物から種を受け取り、未播種地にまく。
- 水辺のスプリンクラーが補給訪問なしで働く。
- アーミーが境界を守り、敵を遠方まで追わない。
- 同じ場所へ過剰に種を使い続けない。
- 移設で在庫が複製されず、設置不可地へ配置できない。
- 後方の設備を巡回しなくても、前線で活動を続けられる。

初期検証は10分間の前線プレイで補給強制の有無を記録する。10分は製品版のサイクル長ではなく、反復できる確認区間。

## P4 昼夜と景観

実施：世界時計、晴れ・曇り・雨、日光と水分、画面の色変化、雨・雲影・水面表現、展望地点、最低限の環境音と操作音を追加。音は権利が確認できる無料素材または自作を使用。

成果：天候が遊びと景色の両方に作用するビルド。

合格条件：

- 晴れた昼は日光による成長促進、雨は水分による促進が観察できる。
- 夜や曇りでも成長が止まらない。
- 一周期を通して必須作業が時間待ちにならない。
- 展望画面が緑化率と時刻と天気を反映する。
- 暗所や雨でも敵、弾、種、芽が読める。
- 効果を増やしてもピクセルパーフェクトと輪郭線なしを維持する。
- ポーズと展望中に世界が停止し、復帰時にまとめて時間が進まない。

## P5 保存と配布可能な体験版

保存データの設計は早期から用意し、この段階で機能と異常系を仕上げる。初めて保存を考え始める段階にはしない。

実施：セーブ／ロード、自動保存、タイトルと再開、クリア表示、操作説明、音量設定、性能改善、Windows向け書き出し。

成果：起動方法付きのWindowsビルド、ソース、依存と素材一覧、検証記録、既知の課題、次段階の提案。

合格条件：

- 新規開始から地域安定、自然緑化100％、クリアまで到達できる。
- 発芽中、戦闘中、地域安定後で保存し、状態を復元できる。
- 終了中の現実時間は進行に加算されない。
- 破損セーブを検出し、バックアップの利用または明確な案内を行う。正常データを黙って消さない。
- 基準PCで通常プレイ60fpsを目指し、負荷試験の結果と限界を記録する。未達なら未達と報告する。
- 30分の継続プレイでクラッシュ、資源増殖、敵の無限蓄積、顕著なメモリ増加がないか確認する。
- エディタからだけでなく、書き出したWindowsビルドを起動して遊べる。
- 全未検証事項を明示する。必須条件が未検証なら、完成済みとは扱わない。

P5が技術的に合格したら、ユーザーが操作感、見た目、ゲームのテンポを確認する。技術合格と商品としての最終承認は分ける。

## P6以降 製品版への拡張

以下は採用済みの拡張方向で、着手範囲をユーザーと決めてから実装する。

1. 多地域とゲートルート、地域ごとの景観、移動と読み込み。
2. クローバー、サボテン、ハス、蓄雨植物、見た目の違う植物。
3. 追加敵、希少種、スキル習得と2枠装備、毒・火・種バズーカ。
4. 夜咲き・発光植物、より豊富な天候演出。
5. アプリ終了中の進行。安定地域を中心に経過時間を計算し、損失・時計変更・長期間不在の扱いを先に定義。
6. 世界全体の完成演出、操作環境拡張、製品向け調整。
