# 第二弾PoC 操作ガイド

更新日: 2026-10-23。

このガイドは第二弾PoCの操作案内です。設計の詳細は[POC2仕様正本](POC2_SPEC.md)を参照してください。PoCは限定的な技術確認と親の限定技術受入を終え、ユーザーの試遊と体験評価を待っています。検証の範囲と限界は[検証記録](VALIDATION.md#poc2-第二弾)を参照してください。

## 起動と開始

Windowsでは [`launchers/run_poc2.bat`](../launchers/run_poc2.bat) を実行します。タイトル画面で「新しく始める」を選びます。保存があれば「続きから」で再開できます。「操作説明」または画面右下の「?」から、ゲーム中にも操作を確認できます。

## 操作

| 操作 | 動作 |
|---|---|
| WASD / 矢印キー | 画面方向へ移動 |
| 左クリック | 種を撃つ。植物を選択中は設置する |
| 右クリック | 水をまく。植物を設置選択中は選択を解除する |
| Q / R | たいあたり / 種バズーカ |
| 下部の植物アイコン | 設置する作物またはおたすけ植物を選ぶ。もう一度押すと解除 |
| M / 左上のミニマップ | 全体マップを開閉。開いている間は時間停止 |
| 全体マップ上でホイール | 1/2/4倍に切替。2/4倍ではカーソル下の場所を保ち、1倍で全域表示へ戻る |
| 全体マップ上でおたすけ植物を選択し、別の場所をクリック | 移動を指示。右クリックまたはEscで選択解除 |
| F5 | 手動保存 |
| Esc | 選択解除、マップを閉じる、またはメニューを開く |
| F1 / ? | 操作説明 |
| N | 音の切替 |
| Tab | 解放済みの植物を順に選ぶ |

全体マップには探索済みの地形を表示し、見つけていない敵や化石は表示しません。おたすけ植物は地図上で選択・移動できます。移動中は通常の作業を止めます。

ミニマップと全体マップはゲーム画面と同じクォータービューの向きで固定されています。全体マップは菱形の地形、ミニマップは円形の枠です。地図上の文字や操作ボタンは正立します。世界外の余白を移動先にすることはできません。

指示先へ到達できない場合、おたすけ植物は現在地で待機し、新しい有効な目的地を指示すると再び動きます。ガトリンガーとスプリンクラーは待機中も敵からの退避を優先し、安全になった後に待機や元の作業へ戻ります。スプリンクラーは水辺での補給途中に退避した場合も、補給と元の持ち場への帰還を再開します。

## 序盤の進め方

1. 初期備蓄の種60個を使って種射撃や植付けを行い、敵の攻撃予兆を見て回避します。通常射撃と播種は各1個、種バズーカは3個、たいあたりは種を使いません。
2. 初期配置の敵や巣を攻略して種を得ます。緑化済み土地は100セルあたり毎分2個、成熟した栽培植物は[仕様正本の栽培植物表](POC2_SPEC.md#栽培植物化石)にある量を共通備蓄へ自動生産します。初期の250セルは毎分5個です。巣から生まれた敵は種を落とさないため、巣を放置した敵の反復撃破では備蓄は増えません。
3. クローバーは初期解放です。栽培植物は緑化済みの地面へ、おたすけ植物は荒地にも設置できます。どちらも水面・建物・他の占有物には重ねて置けません。設置時は下部アイコンを選んで地面をクリックします。
4. 探索や巣の攻略で化石を見つけると、対応する植物が永久解放されます。化石そのものは消費する在庫ではありません。小麦は近くの動物を誘いやすく、ラフレシアは多くの動物を遠ざける一方で虫を誘います。
5. 複数の前線を保つときは、ガトリンガーやスプリンクラーを配置して全体マップから移動させます。ガトリンガーの弾は個体ごとに補給し、設置時または選択時の数量欄で共通備蓄から移します。スプリンクラーは水が尽きると到達できる水辺へ補給に向かいます。

## 植物の選択・補給・撤去

全体マップで植物を選ぶと、撤去や該当する補給のボタンが表示されます。ガトリンガーの補給は量を指定します。撤去前に返還数を確認できます。設置費は撤去時に20%（端数切捨て）返還され、敵に倒された植物からは返還されません。ガトリンガーの未使用弾は手動撤去なら全量戻り、撃破時は失われます。栽培植物を移すときは撤去して植え直してください。

3種のおたすけ植物は、攻撃も被弾もない状態が8秒続くと毎秒1HP回復します。

画面上部に共通種、主人公HP、水、緑化率を表示します。収入の内訳はその表示のツールチップで確認できます。植物のマップアイコンにはHPと、ガトリンガーなら弾薬、スプリンクラーなら水のゲージが出ます。満タンのゲージは隠れます。

## 保存

F5で保存できます。進行中はゲーム内時間60秒ごとにも自動保存します。第二弾専用の保存先は `user://poc2_saves/slot1.json` です。第一弾の保存領域・形式とは分離しています。メニューから「続きから」を選ぶと読込みます。

## 試作の範囲と既知の限界

天候は晴れ固定です。敵や植物などのモデルは試作用で、美術の最終承認を示しません。水面のキャラクター反射の磨き込みは後回しです。植物の誘引・忌避は簡易な近距離の行動選択です。主人公のHPと回復、死亡後の復帰など仕様で確定していない挙動には実装初期値が含まれます。現実装では最大HP100、近くに敵がいない状態で最後に被弾してから8秒後に1HP/秒で自然回復し、成熟したニンジンの3m以内では3HP/秒に増加します。死亡後3秒で開始地点へHP全快で戻り、種は失いません。これらはユーザー確定値ではなく、試遊時に確認・調整するための実装初期値です。詳細は[仕様正本](POC2_SPEC.md)と実装・検証記録を確認してください。

自己検証と独立した論理・境界・GPU確認を実施し、親は限定的な技術受入を行いました。引渡し後の保守境界はPOC2-06、地図のクォータービュー対応はPOC2-07で独立確認し、親が対象を限定して受け入れています。この技術確認は、ゲーム体験や美術の最終評価を意味しません。物理キーボード・マウスを使った操作感、楽しさ、テンポ、美術はユーザーの試遊で確認します。長時間の独立全走、全域性能、全姿勢・照明条件の網羅は未実施です。詳細は[第二弾検証記録](VALIDATION.md#poc2-第二弾)、[保守追補](VALIDATION.md#poc2-06-保守追補)、[マップ追補](VALIDATION.md#poc2-07-マップのクォータービュー対応)を参照してください。
