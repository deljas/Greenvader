# PoC3 作業版 操作ガイド

更新日: 2026-10-24。

このガイドは現在のPoC3作業版の遊び方です。リポジトリ直下の[`run_game.bat`](../run_game.bat)から起動します。確定仕様は[PoC3仕様正本](POC3_SPEC.md)、現在地は[STATUS](STATUS.md)を参照してください。

## 起動と開始

タイトル画面で「新しく始める」を選んでください。PoC3の保存先は `user://poc3_saves/slot1.json` です。旧PoC・PoC2のセーブは自動で読み込まず、移行もしません。

## 開始地点

新しいゲームは224×224マスの中央、座標(112,112)付近から始まります。初期緑地は半径約3m、初期種は60です。緑地から毎分約3.54種を得られ、水辺は数歩先にあります。遠くの巣は時間だけでは活動せず、主人公の接近や緑化によって前線が届くと動き始めます。

## 開始地点からの距離による敵階級

敵・巣は開始地点からの距離で3段階に分かれます。階級は配置時に決まり、移動後も変わりません。遠い階級ほどHP・攻撃力・初期配置敵の種報酬が増えます。巣から生まれた敵は巣の階級を引き継ぎますが、種を落としません。敵の速度や攻撃予兆は距離階級で変わりません。

## バッタの群れと食害

バッタの群れは近くの草へ向かい、同じ草へ重ならずに分散します。草を3秒食べ続けると1マスが荒地になります。食害完了前に倒せば草は残ります。主人公・栽培植物を直接攻撃せず、植物のあるマスや安定地域も避けます。ラフレシアは虫を引き寄せます。巣から生産された敵は種を落とさず、巣を破壊すると報酬を得られます。

## 現在の操作

| 操作 | 現在の動作 |
|---|---|
| WASD / 矢印キー | 画面方向へ移動 |
| 左クリック | 種を撃つ。植物を設置選択中は設置する |
| 右クリック | 通常は水やり。植物設置選択中は選択解除し、水やりしない。一覧/マップでは保持・選択を取り消す |
| Shift+左 / 右クリック | スキル1「たいあたり」 / スキル2「種バズーカ」 |
| 左下のお気に入り5枠 / 1〜5 | 枠の植物を選ぶ。同じ枠で解除し、別枠で切り替える（初期登録はクローバーと空き4枠） |
| E | 植物一覧を開閉 |
| 植物一覧の行 | クリック保持後に枠を押すか、ドラッグ＆ドロップでお気に入り登録 |
| Tab / ミニマップ / 閉じるボタン | 全体マップを開閉。開いている間は時間停止 |
| 通常画面のホイール | 播種幅を1×1 / 3×3 / 5×5 / 7×7で選択 |
| マップのホイール / 一覧のホイール | マップのズーム / 一覧スクロール |
| 全体マップで植物を選び、別地点をクリック | おたすけ植物の移動先を指示 |
| F5 | 手動保存 |
| Esc | 設置選択を解除。UI中は取消/戻る。通常時はメニューを開く |
| F1 / ? | 操作説明 |
| メニュー | 音量・ミュート |

スキル1「たいあたり」は種を使わず近距離で戦う技、スキル2「種バズーカ」は種を使う強力な攻撃です。操作中はQ/R/M/Nを使いません。スキルは新たなクリックで発動します。PoC2時点の古い操作案内は[PoC2ガイド](POC2_GUIDE.md)を参照してください。

## 範囲播種

通常画面のホイールで幅を1×1 / 3×3 / 5×5 / 7×7に切り替えます。照準マスが中心です。プレビューは播ける場所と必要な種数を示します。水面・建物・種や草があるマス・植物の占有マスは対象外です。種が足りない場合は中心に近い場所から播きます。

種弾は1個を発射します。敵や巣に当たると種1個分の通常攻撃になり、周囲には播きません。地面に着弾した時点で実際に播けた数を消費します。壁で止まるか播ける場所がなければ種は返ります。

## 水やりと成長

栽培植物は未給水でも枯れずに育ちますが、成熟まで設定時間の約2倍かかります。一度給水すると通常速度になり、追い水でさらに速くなることはありません。成長途中で給水しても進捗は保たれ、植え直した株は乾いた状態から始まります。

草は未給水だと基準時間の約2倍で育ち、成長中に一度給水すると基準速度になります。成熟した草への水やりは種の収入や自然拡張を増やしません。荒地は水だけでは緑化せず、食害や自然拡張で新たに生えた草は乾いた状態で始まります。

スプリンクラーは未給水の栽培植物を優先し、次に成長中の未給水草へ向かいます。一度有効に散水すると水を1消費し、給水済みの対象へ繰り返し散水しません。水切れ時は補給して持ち場へ戻ります。

## 敵・植物の表示

敵や植物は3D地形上に2D画像で表示します。画像の足元や影、状態表示はゲーム判定と分けて扱い、仮画像がない対象は従来の表示を使います。

## 水面に映るスプライト

PoC3の水面反射は本画面と同じ解像度で表示します。プレイ時は水辺で反射像の見え方も確認できます。

## おたすけ植物の仕事と退避

設置時は地面上に半径6mの薄い範囲円を表示します。設置後の持ち場・範囲・仕事先はマップで個体を選ぶと表示します。個体のアイコンを選ぶと、撤去やガトリンガーへの種補給ボタンが出ます。

アーミーは味方を攻撃中の敵や草を食べる敵を優先して守り、巣へ追いかけません。ガトリンガーは渡した種で空き地を播きます。スプリンクラーは未給水の栽培株や草へ給水します。危険を避けた後、安全になると仕事へ戻ります。仕事がない作業役は帰還後にZzzを表示し、新しい仕事で解除します。

植物を解放したらEの一覧からお気に入り枠へ登録し、一覧を閉じてその枠を選んで設置します。ガトリンガーの残弾はマップの補給ボタンから渡します。

## 栽培植物の価格と撤去

次に植える同種の栽培植物の価格は、マップ上の同種株数に応じて上がります（`ceil(基本コスト × 1.05^n)`、未成熟株を含む）。撤去すると実際に支払った額の1/5を切り捨てて返します。敵に破壊された株は返還しません。栽培植物はマップ上で選択し、撤去ボタンから取り除きます。

## 敵・巣・化石の表示

通常画面では、カメラ内にいる生存中の敵・固定巣・動く親玉を距離だけを理由に非表示にしません。

マップでは主人公の視界、生存中のおたすけ植物の索敵範囲、緑化済み土地の検知に応じて敵や巣を表示します。発見済みの固定巣と探索化石は破壊・回収まで記憶し、動く親玉は検知中だけ表示します。化石をマップで見つけただけでは植物は解放されません。主人公が現地へ近づくと化石を回収して植物を解放します。巣の化石報酬は巣の破壊時に取得します。

## セーブの区分

作業版は `user://poc3_saves/slot1.json` へ保存します。F5で手動保存し、自動保存はゲーム内時間60秒ごとです。旧PoC・PoC2のセーブは引き継ぎません。

## 植物の種類と初期値

栽培植物は成熟すると固有の効果を発揮します。成熟時間と初回の基本値は次のとおりです。設置価格は同種の株数に応じて上昇します。

| 植物 | 主な役割 | 基本価格 | 種/分 | 成熟時間（給水済み） |
|---|---|---:|---:|---:|
| クローバー | 基本の種生産 | 10 | 2 | 20秒 |
| ニンジン | 近くの主人公のHP自然回復を速める | 15 | 1 | 15秒 |
| 小麦 | 種を多く生産するが動物を少し引き寄せる | 40 | 12 | 45秒 |
| ラフレシア | 多くの動物を遠ざけ、虫を引き寄せる | 40 | 2 | 30秒 |
| スイカ | 場所を取り、まとまった種を生産する | 120 | 30 | 90秒 |
