# PoC3 作業版 操作ガイド

更新日: 2026-10-24。

このガイドは現在の起動版に限った暫定案内です。画面表示は「PoC3 作業版」ですが、ゲーム機能はPoC2共有コードをもとに開発中で、PoC3仕様の全機能が実装済みという意味ではありません。仕様と合意済み範囲は[PoC3仕様正本](POC3_SPEC.md)、進捗は[STATUS](STATUS.md)、確認範囲と未確認事項は[検証記録](VALIDATION.md)を参照してください。

## 起動と開始

リポジトリ直下の [`run_game.bat`](../run_game.bat) から起動します。タイトル画面で「新しく始める」を選んでください。新しい作業版の保存先は `user://poc3_saves/slot1.json` です。旧PoC・PoC2の保存データは自動で読み込まず、移行もしません。旧保存領域・ファイルは別のまま保たれます。

## 開始地点

新しいゲームは224×224マスの中央付近、マップ座標(112,112)から始まります。初期緑地は半径約3mの177マスで、初期種は60です。初期緑地からの収入は3.54種/分、水辺は約3.2m先です。開始直後に敵や巣が隣接せず、最寄りの小巣は約14m先にあります。遠方の巣は時間だけでは活動せず、主人公の接近や緑化で前線が届くと起動します。これらは中央配置の限定確認で、全マップの進行や攻略時間、楽しさの評価ではありません。検証範囲は[STATUS](STATUS.md)と[検証記録](VALIDATION.md)を参照してください。

## 開始地点からの距離による敵階級

敵・巣は固定開始位置から初期配置地点までの距離に応じて、18m未満・18m以上32m未満・32m以上の階級に分かれます。階級は配置時に決まり、移動後も変わりません。HP・攻撃力・初期配置個体の報酬倍率はそれぞれ近距離から1/1.3/1.7、1/1.2/1.4、1/1.5/2です。報酬倍率適用後の端数は切り捨てます。巣から後で生産された敵は親の階級を引き継ぎますが、報酬は0です。階級による速度・攻撃予兆・生産能力・見た目の違いはありません。この範囲の限定確認で、難易度や楽しさの評価ではありません。詳細は[検証記録](VALIDATION.md)を参照してください。

## バッタの群れと食害

基本6匹の群れは近くの草を狙い、同じマスへ重ならずに分散します。草の上で3秒連続して食べると1マスを荒地にし、食害完了前に倒せば草は残ります。主人公や栽培植物を直接攻撃せず、植物占有マスと安定地域を避けます。ラフレシアは近くの草を狙うバッタを引き寄せます。初期配置個体は種1個を基礎報酬として距離tier倍率を受け、巣から生産された個体の報酬は0です。小巣は既存の20秒周期で最大6匹を補充し、初期個体込みで同じ巣の生存数は最大12匹です。仮の6脚表示と食害中の圧縮姿勢を確認していますが、連続アニメーションや緊張感の評価は未実施です。全マップ100%緑化の統合確認も残っています。詳細と未確認範囲は[検証記録](VALIDATION.md)を参照してください。

## 範囲播種

通常画面のホイールで幅を1×1 / 3×3 / 5×5 / 7×7に切り替えます。照準マスは常に中心です。プレビューは播けるマスを緑、不足分を黄で示し、種アイコンと予定数を表示します。水面・建物・既存の種や草・植物の占有マスには播けません。種が足りない場合は中心に近い有効マスから播きます。

通常射撃は1個の種弾を発射します。敵や巣に当たると種1個で通常攻撃し、周囲へ播種しません。地面への着弾ではその時点で実際に播けた数を精算します。壁で止まるか播けるマスがない場合は、預けた種が返ります。敵・巣への予測時は範囲プレビューを隠し、1個での攻撃として表示します。壁が予測される場合は播種不可として表示します。水・成長、栽培価格など他機能の実装状態は[STATUS](STATUS.md)を参照してください。

## 水やりと成長

栽培植物は未給水でも枯れずに育ちますが、成熟まで設定時間の約2倍かかります。一度給水すると成熟まで通常速度で育ち、濡れた株への追い水による追加加速はありません。成長途中で給水しても、そこまでの進捗は保たれます。植え直した株は乾いた状態で始まります。

成長中の草も乾いたままでは基準時間の2倍かかります。成熟までに一度給水すると元の成長速度へ戻りますが、成熟した草への水やりは種の収入や自然拡張を増やしません。荒地は水だけでは緑化せず、食害後の草や自然拡張で生えた草は乾いた状態で始まります。

スプリンクラーは未給水の栽培植物を優先し、次に成長中の未給水草へ向かいます。一度有効に散水すると水を1消費し、給水済み対象へ繰り返し散水しません。水切れ時は補給へ向かい、補給後は元の持ち場へ戻ります。おたすけ植物の仕事・退避・表示はHELPERSとして限定技術受入済みです。詳細と未確認範囲は[STATUS](STATUS.md)と[検証記録](VALIDATION.md)を参照してください。

## 敵・植物の表示

共通の2D表示基盤で、仮画像を用いたboar・clover・carrotの代表表示を確認しています。画像の足元や影、状態表示はゲーム判定から分離し、画像が用意されていない敵・植物は従来のmesh表示を保ちます。表示基盤とHELPERSの一部機能表示の限定確認であり、全対象のスプライトや完成アート、最終mask版GPU確認は未完了です。詳しくは[検証記録](VALIDATION.md)を参照してください。

## おたすけ植物の仕事と退避

設置時は地面上に半径6mの薄い範囲円を表示します。設置後の持ち場・範囲・仕事先はマップで選択したときに表示します。半径6mの仕事範囲、アーミーの追跡上限8m、退避開始3.5m/解除4.5mは試作用の仮値です。

アーミーは味方や栽培植物を攻撃中の敵、草を食べる敵、その他の侵入敵の順に対処し、巣へ自分から攻め込みません。ガトリンガーは渡された種だけを個体弾として播き、共有備蓄を自動消費しません。スプリンクラーは未給水の栽培株を優先し、次に未給水の成長中の草へ水をやります。危険を避けた後、安全になれば仕事へ戻ります。仕事のない作業役は帰還後3秒でZzzを表示し、新しい仕事で解除します。アーミーの警戒や資源切れ・補給・退避中はZzzを出しません。

同じ短い局所条件でガトリンガーの播種、スプリンクラーの給水、アーミーの食害防衛への寄与を比較し、仮の機能が働くことを限定確認しています。通常の全マップ経済や楽しさを評価した結果ではありません。仮表示の連続動作や完成美術、物理入力、全マップ100%は未確認です。詳細は[検証記録](VALIDATION.md)を参照してください。

## 栽培植物の価格と撤去

次に植える栽培植物の価格は、同じ種類の現存株数 `n` に応じて `ceil(基本コスト × 1.05^n)` で計算されます。未成熟株も数え、別種類の株やおたすけ植物は数えません。撤去や敵による破壊で株数が減ると、次の価格もその株数に応じて下がります。撤去時はその株を植えたときの支払額の1/5を切り捨てて返し、敵に破壊された株からは種を返しません。これらはCROP-PRICINGの限定受入範囲で、混植の動機や全体の経済バランスは未評価です。詳細は[検証記録](VALIDATION.md)を参照してください。

## 敵・巣・化石の表示

通常画面では、カメラ内にいる生存中の敵・固定巣・動く親玉は距離だけを理由に非表示にならないよう修正しました。建物による遮蔽やマップ上の敵・巣・化石表示はこの修正の対象外です。

マップでは、通常画面内・生存中のおたすけ植物の索敵範囲・緑化済みの土地による検知に応じて敵や未発見の巣を表示します。発見済みの固定巣と探索化石は離れても破壊/回収まで記憶し、動く親玉は検知中だけ表示します。化石はマップで発見しただけでは植物を解放せず、主人公が近づくと回収します。巣報酬の化石の扱いは維持しています。これはマップ表示・記憶の限定受入で、独立GPU再実行や物理入力、広い回帰などは未確認です。詳細は[検証記録](VALIDATION.md)を参照してください。

お気に入りの初期登録はクローバー1枠と空き4枠です。植物を解放したら、Eの一覧から使いたい枠へ登録してください。

## セーブの区分

作業版はPoC3用の保存先 `user://poc3_saves/slot1.json` と保存形式 `greenvader_poc3_1` / `greenvader-poc3` version 3を使います。F5で手動保存し、既存の自動保存はゲーム内時間60秒ごとです。旧PoC/PoC2形式の保存は引き継がず、旧保存領域へ書き込みません。これは保存先・形式の分離に関する限定確認であり、PoC3の新機能全体や将来追加される状態の保存対応を保証しません。保存分離の検証結果は[検証記録](VALIDATION.md)を参照してください。
