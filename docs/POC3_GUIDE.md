# PoC3 作業版 操作ガイド

更新日: 2026-10-24。

このガイドは現在の起動版に限った暫定案内です。画面表示は「PoC3 作業版」ですが、ゲーム機能はPoC2共有コードをもとに開発中で、PoC3仕様の全機能が実装済みという意味ではありません。仕様と合意済み範囲は[PoC3仕様正本](POC3_SPEC.md)、進捗は[STATUS](STATUS.md)、確認範囲と未確認事項は[検証記録](VALIDATION.md)を参照してください。

## 起動と開始

リポジトリ直下の [`run_game.bat`](../run_game.bat) から起動します。タイトル画面で「新しく始める」を選んでください。新しい作業版の保存先は `user://poc3_saves/slot1.json` です。旧PoC・PoC2の保存データは自動で読み込まず、移行もしません。旧保存領域・ファイルは別のまま保たれます。

## 現在の操作

| 操作 | 現在の動作 |
|---|---|
| WASD / 矢印キー | 画面方向へ移動 |
| 左クリック | 種を撃つ。植物を設置選択中は設置する |
| 右クリック | 水をまく。設置選択中は選択を解除する |
| Q / R | たいあたり / 種バズーカ |
| 左下のお気に入り5枠 / 1〜5 | 枠の植物を選ぶ。同じ枠で解除し、別枠で切り替える |
| E | 植物一覧を開閉 |
| 植物一覧の行 | クリック保持後に枠を押すか、ドラッグ＆ドロップでお気に入り登録 |
| M / 左上のミニマップ | 全体マップを開閉。開いている間は時間停止 |
| 全体マップのホイール | マップ表示倍率を切り替える |
| 全体マップで植物を選び、別地点をクリック | おたすけ植物の移動先を指示 |
| Tab | 解放済み植物を順に選択 |
| F5 | 手動保存 |
| Esc | 選択解除、マップを閉じる、またはメニューを開く |
| F1 / ? | 操作説明 |
| N | 音の切替 |

これは現時点の実装操作です。お気に入り枠と植物一覧の実装・保存は限定技術受入済みですが、合意済み操作全体はまだ実装されていません。Q/R/M/NとTabは旧操作のままで、合意済み割当への再整理やShiftスキル入力はPOC3-INPUTで作業中です。WORLD-LAYOUTは接続準備のみです。第二弾当時の詳しい進め方・植物の挙動は[PoC2ガイド](POC2_GUIDE.md)にありますが、同ガイドは保全タグ `poc2-before-poc3` 時点の履歴です。

通常画面では、カメラ内にいる生存中の敵・固定巣・動く親玉は距離だけを理由に非表示にならないよう修正しました。建物による遮蔽やマップ上の敵・巣・化石表示はこの修正の対象外です。

マップでは、通常画面内・生存中のおたすけ植物の索敵範囲・緑化済みの土地による検知に応じて敵や未発見の巣を表示します。発見済みの固定巣と探索化石は離れても破壊/回収まで記憶し、動く親玉は検知中だけ表示します。化石はマップで発見しただけでは植物を解放せず、主人公が近づくと回収します。巣報酬の化石の扱いは維持しています。これはマップ表示・記憶の限定受入で、独立GPU再実行や物理入力、広い回帰などは未確認です。詳細は[検証記録](VALIDATION.md)を参照してください。

お気に入りの初期登録はクローバー1枠と空き4枠です。植物を解放したら、Eの一覧から使いたい枠へ登録してください。

## セーブの区分

作業版はPoC3用の保存先 `user://poc3_saves/slot1.json` と保存形式 `greenvader_poc3_1` / `greenvader-poc3` version 3を使います。F5で手動保存し、既存の自動保存はゲーム内時間60秒ごとです。旧PoC/PoC2形式の保存は引き継がず、旧保存領域へ書き込みません。これは保存先・形式の分離に関する限定確認であり、PoC3の新機能全体や将来追加される状態の保存対応を保証しません。保存分離の検証結果は[検証記録](VALIDATION.md)を参照してください。
