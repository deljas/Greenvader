# POC2-07 独立検証の準備

対象は親が後から指定する凍結版。準備時点では Godot/import を実行していない。
編集範囲は独立テストとこの証拠ディレクトリのみ。ゲーム実装は変更しない。

- 方向・縦横比: 実際の `world.camera.unproject_position` を地面4方向へ適用し、地図の同一点との差を一様スケールだけで比較する。実装の投影式を期待値へ写さない。
- 地形・逆変換: 地図テクスチャ上の固定格子サンプルについて、クリック変換先のセルと既知地形色を照合する。実カメラ照合と組み合わせ、同じ誤投影が描画・クリック双方へ入る場合を捕捉する。
- 1/2/4倍ズーム、セル中心へ丸める移動指示、菱形外の余白、選択・補給popup、世界時計停止をエンジン内入力で確認する。
- 未知の敵・巣・化石は、現在視界を消した画像と、当該個体をテストセッションから除去した画像が一致することを確認する。
- 移動直後のミニマップ、全体表示、選択・ゲージ・活動範囲、popupを640×360 GPU画像へ保存して目視する。
- 親の新freeze、直前16 source、第一弾91 baselineをhash照合する。今回許可されたsource以外の変更は親へ返す。

実行は `root.unfocusable=true`、`Input.parse_input_event` のみ。通常saveは触らず、テストのsave_dirを分離する。
物理マウス・キーボード、書き出し後の実行、広いbalance/save/長時間回帰は NOT_RUN。
失敗時は条件を緩和せず、期待・実際・最小再現と画像/ログを親へ返す。
